## 1 智能网联终端类型
### 1.1 AI 摄像头

AI 摄像头为定点安装的摄像头，具备实时视频查看、问题图片上传等功能。其中涉及到的流量主要包括：

1. 视频推流：该部分数据不同项目区别较大，与用户使用习惯有关
2. 图片上传：一般为定期采集，图片流量可计算
3. 心跳、设备状态、告警事件、OTA 升级等流量
token 费用主要为图片 AI 识别的 token 费用 *（需要核实 AI 摄像头识别是边缘识别还是云端）*
目前常见的流量来源一般为单机配备的物联网卡
### 1.2 自动驾驶机器人

自动驾驶机器人是一个复杂的集合，其中包括网联终端、摄像头等多种网联终端设备，因此其流量费用主要包括：

1. 视频推流
2. 图片上传
3. 控制指令、定位、地图/路径、遥测、日志、OTA 和异常回传
一般机器人中会装备 ADU 和 T-box 两种设备，TBOX 通常主要上传定位、车辆状态、故障码、里程、电池和驾驶行为数据，ADU
token 费用主要为图片 AI 识别的 token 费用
目前常见的流量来源一般为单机配备的物联网卡
### 1.3 车载网联终端

车载网联终端是一个大的分类，包括所有车辆上的网联终端，除机器人外，还包括普通车辆加装的网联终端，主要负责车辆状态、数据等上报。因此其流量费用主要包括：

1. 视频推流
2. 图片上传
token 费用主要为图片 AI 识别的 token 费用 *（需要核实 AI 摄像头识别是边缘识别还是云端）*
目前常见的流量来源一般为单机配备的物联网卡（T-BOX）

### 1.4 对讲机

对讲机是环卫工人移动作业的工具，具备定位、语音通话、图片上传等功能。因此其流量费用主要包括：

1. 定位上报
2. 对讲 / 音视频通话
3. 图片/视频上传的流量
4. 设备心跳和 OTA 等其他数据上传
## 2 流量成本现状调研

### 2.1 流量采购方式

#### 2.1.1 统一采购

目前项目的物联网卡大多均由公司统一采购，根据项目计划进行购买。采购的计费周期为年度

对于同一套餐的物联网卡为共享流量池，且为企业共享池

定向流量和通用流量不能混池

对于到期的流量不跨月结转，月底清空，次月恢复

当物联网卡首次插入设备激活时，物联网卡即与设备自动绑定。如果物联网卡被挪用到其他设备上使用，将触发机卡分离停机 (被锁卡)。

注意：实际使用流量不等于实际流量成本，需要考虑到到期后流量如何处理

#### 2.1.2 项目自行采购

对于香格里拉等外场项目，由于当地要求，因此是项目内自行采购的流量卡套餐

### 2.2 不同设备流量套餐情况

1. 针对公司统一采购的情况，目前不同项目均采用以下套餐内容：

	- **对讲机：** 移动 4G 网络， 10GB 流量每月。资费 48 元/年
	- **ADU：** 移动 5G 网 ，100GB 流量每月。资费 205 元/年（老款 ADU 为电信 5G 网，100GB 流量每月。500 元/年。）
	- **TBOX：** 联通 4G 网 ，10GB 流量每月。48 元/年
	- **AI 摄像头:**  移动 4G 网络， 10GB 流量每月。资费 48 元/年
2. 对于香格里拉等外场项目，由于当地要求，因此是项目内自行采购的流量卡套餐，具体套餐价格由项目决定

### 2.3 超出流量套餐外计费

移动和电信超出套餐按照 0.29 元/MB 计费，联通按照 0.2048 元/MB

没有阶梯计费

从流量池的角度来看，目前尚未出现过超出企业套餐流量池外的情况。如果超额可以采取买新卡加流量池/或者充值流量包的方式来补充流量

- 买新卡，则可以参考套餐价格
- 充值流量包，价格为 10G/70 元，100G/500 元
对于单个设备（单张卡）来说，其超出本身卡套餐后，可以通过企业共享流量池继续正常使用。但是**如果超过自身流量 10 倍的话会停机**（从实际数据看，每月存在少量 sim 卡会超出 10 倍流量而停机）
### 2.4 流量结转

不能跨月，当月结算月底清零，次月恢复

### 2.5 项目流量采购成本估算

流量卡为项目发起，公司统一采购，因此项目上的流量采购成本目前基本为：

```
项目流量采购成本= 卡数量 * 套餐价格
= 在用对讲机数量 * 对讲机sim卡套餐 + 在用机器人ADU数量 * ADU sim卡套餐 + 在用车辆T-BOX数量 * T-BOX sim卡套餐 + AI摄像头数量 * 摄像头sim卡套餐
```

至于单设备的流量采购成本可等同于对应流量卡的套餐费用

期间流量结转和流量超额均不做限制，共享公司流量池。这其中可能存在不同项目之间的交叉补贴（以共享流量池的方式）

如果按实际设备使用的流量资源来计算，其真实流量成本会与套餐费用有差异

### 2.6 不同设备的典型流量计算与成本

目前从统计学的角度，结合不同设备类型每月实际消耗量进行均值估算

#### 2.6.1 对讲机

结合前期调研的深圳石井项目的数据，单台对讲机平均月度流量消耗约为 8.6 GB，年度约为 103.2GB

结合流量套餐，其费用大概为 48 元/年

#### 2.6.2 AI 摄像头

AI 摄像头的流量消耗主要由图片上传和实时视频推流组成

##### 2.6.2.1 视频推流流量

实时视频推流与视频的码率以及推流时长（与用户的使用习惯关联）有关

```
视频推流月流量 = 视频推流月时长(秒) * 码率(Mbps) / 8 /1024
```

以 2K 为例，单路视频小时流量消耗约为 2GB

>估算的话， 4K 的像素数是 2K 的 **2.25 倍** ，流量也是同等换算
##### 2.6.2.2 图片上传流量

图片上传的费用可通过图片上传的频率进行计算。

1. 采样频率

| 采样时段                       | 采样频次      |
| -------------------------- | --------- |
| 08:00~11:00                | 10 分钟 / 次 |
| 11:00~13:30                | 15 分钟 / 次 |
| 13:30~17:00                | 10 分钟 / 次 |
| 17:00~21:00                | 30 分钟 / 次 |
| 21:00~ 次日 08:00            | 60 分钟 / 次 |
| 按上述规则计算，单台摄像头每日图片采样合计 68 张。 |           |

2. 采样质量：单张采样图片全程流量按照 550KB 计算
3. 月度流量计算

```
摄像头图片月上传流量 = 图片月采样数量 * 单张照片上传耗费流量（KB）
				  = 68* 30 * 550=1122000 KB/月= 1.12 GB/月
```

##### 2.6.2.3 实际数据估算

结合前期调研的深圳石井项目的数据，单台摄像头平均月度流量消耗约为 10 GB，年度约为 120GB

结合流量套餐，其费用大概为 48 元/年

#### 2.6.3 机器人

机器人中的流量费用包括 ADU 和 T-BOX。X1 X2 T2 X3 物联网卡都在 tbox 里面

根据平行驾驶的数据推算，单车小时流量消耗值约为 2.2GB，按照每天 5h 工作量来算，单月流量约为 330GB，年度约为 3960GB

结合流量套餐，现有的 100G 每月套餐超额（但是实际不一定会产生超额费用，因为企业共享流量池未超，但是**如果超过自身流量 10 倍的话会停机**）

- 套餐费用约为 205 元/年
- 考虑超额流量，超额部分费用约为 471.5 元/年（按照套餐中的单位流量成本计算）
- 累计成本为 676.5 元/年

### 2.7 流量结算计算

结合现有的调研结果，流量结算统一以公司采购的流量卡套餐价格进行结算，未按照实际使用流量进行结算，也未出现过超额流量

### 2.8 关于流量池模式的调研

流量池模式分为两种：

传统【前向流量池（同档位套餐聚合池）】：不支持不同套餐卡入池；适用于单卡流量利用率高的场景

统付流量池（后向共享池）：可以，卡本身没有独立流量套餐，全部共用一个总流量池；适用于不同卡流量差异较大的场景

统付也有两种签约模式：

- A、预购流量包模式：先买一大包流量，月底清零，没用完作废；
- B、**实耗计费（按实际消耗后结算）**：不预购包，每月按实际消耗 GB × 签约单价结算。👉**这个模式才真正解决大量低流量卡的浪费问题**，但不是所有地区运营商开放，一般要求卡量≥100~200 张，部分协议有最低月消费。

| 项目          | 前向流量池（同档位）     | 统付（后向）流量池                      |
| ----------- | -------------- | ------------------------------ |
| 单卡基础成本      | 固定套餐费，卡必扣满额    | 功能费，普遍低于前向单卡套餐费                |
| 流量成本        | 流量绑定卡片，卡买多少算多少 | 流量单独采购，全局共享                    |
| 闲置成本        | 高：卡闲置也要交全套套餐费  | 较低：卡只交功能费，流量按需采购               |
| 能不能混不同流量需求卡 | ❌不能，必须同套餐      | ✅可以，适合大流量、小流量设备混合              |
| 开通门槛        | 低，几十张卡即可       | 偏高，集团大客户，一般≥50‑100 张起签，有最低消费约束 |
| 预算确定性       | 极强：每月费用几乎固定    | 中等：卡费固定，流量随业务波动                |
| 套外单价        | 套外很贵（MB 计价）    | 套外按 GB 计价，相对温和，但高于池内采购价        |
| 存量卡改造       | 存量不同套餐卡无法进池    | 存量卡要改资费，重新签约才能切统付池             |

### 3.4 单位 token 成本计算

#### 3.4.1 标准每百万 token 成本

标准每百万 token 成本主要用于作为外部业务收费的成本基础，避免因为月度之间的 token 数变动导致的成本波动

按照服务器利用率 100% 的条件来计算理想状态下的 token 成本计算，分为输入和输出两部分

首先需要拆分出输入和输出阶段的成本池

```
月度总成本 = 输入阶段成本池 + 输出阶段成本池
标准输入阶段分摊比例 = 标准输入阶段GPU时间 ÷ 标准总GPU时间
标准输出阶段分摊比例 = 标准输出阶段GPU时间 ÷ 标准总GPU时间
```

以上公式中的标准输入阶段和输出阶段的 GPU 时间可以通过标准场景压力测试得出的结果赋值，也可以根据历史日志信息进行取值

对于图片识别，GPU 时间通常比输出 Token 更适合作为主要成本分摊依据，因为图片编码、视觉特征提取可能消耗大量算力，但输出文字很少

```
标准输入阶段成本池 = 共同成本 × 标准输入阶段分摊比例

标准输出阶段成本池 = 共同成本 × 标准输出阶段分摊比例
```

```
标准每百万输入token成本=输入阶段成本池 ÷ 输入token实用产能 x 1000000
标准每百万输出token成本=输出阶段成本池 ÷ 输出token实用产能 x 1000000
```

token 使用量越多，服务器的利用率越高，单位 token 成本越便宜

标准 token 产能，可以通过一定场景下，通过压力测试得出可持续吞吐量，如持续 30 分钟或者 1h，再由可持续吞吐量换算得到标准月度产能，可考虑 5% 的冗余，计算得出实用产能

考虑到目前公司提供的 AI 推理服务以图片 AI 识别为主，因此在压力测试时，可以按照图片 AI 识别的标准场景进行标准月度产能的计算

#### 3.4.2 实际每百万有效 token 成本

实际每百万有效 token 成本主要用于公司内部衡量实际成本

AI 服务搭建完成后，总拥有成本已知，但是可能存在空闲的算力，因此按照实际输出的有效 token 量进行单位成本计算

对于失败或者重试的 token 则不纳入单位 token 成本的计算

同样需要拆分出输入和输出阶段的成本池

```
月度实际总成本 = 实际输入阶段成本池 + 实际输出阶段成本池
实际输入阶段分摊比例 = 实际输入阶段GPU时间 ÷ 实际总GPU时间
实际输出阶段分摊比例 = 实际输出阶段GPU时间 ÷ 实际总GPU时间
```

需要特别注意，“实际总 GPU 时间”通常指**GPU 实际被推理任务占用的时间**，而不是按照 24h 计算

```
实际输入阶段成本池 = 共同成本 × 实际输入阶段分摊比例

实际输出阶段成本池 = 共同成本 × 实际输出阶段分摊比例
```

```
实际每百万输入token成本=实际输入阶段成本池 ÷ 实际有效输入token x 1000000
实际每百万输入token成本=实际输出阶段成本池 ÷ 实际有效输出token x 1000000
```

这里的实际有效 token 总览包括成功请求的输入 token 和成功请求的输出 token

需要结合标准 token 成本和实际有效 token 成本，定义出单位输入 token 单价和单位输出 token 单价

## 4 业务计费模型

用户建立面向客户的收费模型，收费可以在成本核算的基础上叠加适当的策略进行设计

```
充值费用-流量费用-AI推理服务费用=账户余额
```

### 4.1 流量计费策略
#### 4.1.1 根据成本换算业务售价

在已经计算得到标准成本单价的基础上，可以结合公司期望的毛利率进行业务单价的确定。此外，还可以根据需要增加风险准备金

```
业务单价 = 标准单位成本 ÷ (1 - 毛利率) + 风险准备金
```

#### 4.1.2 流量计费
##### 4.1.2.1 按实际流量计费

适用场景：

```
费用 = 实际使用GB × 单价
```

##### 4.1.2.2 按设备包月

适用场景：

```
基础费用 = 设备数 × 设备月费
超额费用 = 超出套餐的GB × 超额单价
```

##### 4.1.2.3 阶梯计费

适用场景：

用量越大，单价越低

### 4.2 AI 推理服务计费
#### 4.2.1 主流大模型计费模式调研

当前主流大模型的计费方式普遍采用 **“按量后付费”模式**，即按实际使用的输入 Token 和输出 Token 数量分别计费，并区分输入与缓存输入的价格

部分国内厂商还会区分输入的 token 范围，来区分输入、输出的定价

此外，针对图片生成/编辑等服务，按照图片张数进行计费

#### 4.2.2 按实际 Token 计费

```
AI推理服务费用 
=（实际有效输入token数 x 有效输入token单价） + （实际有效输出token数 x 有效输出token单价）
```

#### 4.2.3 按成功调用次数计费

考虑到公司主要的 AI 推理服务为图片识别，因此按成功调用次数的计费模式也较为适用，且客户更容易理解

```
AI 推理服务费用
= 成功识别图片数 × 单张图片识别单价
```

再进一步，还可以根据图片质量，区分不用质量图片的计费单价

**关于图片识别单价**

图片识别所消耗的 token 可以分为几部分：

1. 输入阶段消耗 Token
2. 图片编码消耗 token
3. 输出阶段消耗 token
在压力测试阶段，可以测试图片的识别成本
- 分析不同图片分辨率的资源消耗；
- 建立图片规格与成本的关系；
#### 4.2.4 按月度资源包计费

适用于大型项目

```
AI推理服务费用
= 基础服务费（包含识别次数） + 超出次数费用
```
