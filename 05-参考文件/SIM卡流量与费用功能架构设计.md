# SIM 卡流量与费用功能架构设计

| 项目 | 内容 |
| --- | --- |
| 所属系统 | 车辆管理系统 |
| 文档性质 | 产品与功能架构参考方案 |
| 版本 | V1.0 |
| 日期 | 2026-09-14 |
| 状态 | 待进一步确认 |

> 本文档用于明确 SIM 卡流量、流量费用和车辆成本之间的产品架构与核算口径，不替代后续正式 PRD。

## 1. 背景与目标

公司的车辆、自动驾驶机器人、对讲机、AI 摄像头等设备使用大量物联网 SIM 卡。当前 SIM 卡多采用公司统一采购和企业共享流量池模式，存在以下问题：

1. SIM 卡、终端、车辆与项目的关系未形成完整历史链路。
2. 单卡、单车和项目的实际流量消耗与成本不清晰。
3. 采购成本与实际流量消耗存在差异，共享流量池可能存在闲置和跨项目补贴。
4. 缺少运营商账单、内部核算结果与车辆成本之间的对账闭环。

建设目标是形成“卡、量、价、车、项目”的完整链路，支持流量查询、利用率分析、费用核算、成本归集、对账和套餐优化。

## 2. 总体设计原则

1. **外部平台管资源**：物联网卡平台是 SIM 卡状态、套餐、流量池成员和原始用量的权威数据源。
2. **车辆系统管业务关系**：车辆管理系统负责 SIM 卡与终端、车辆、其他资产及项目的绑定关系。
3. **费用核算与运营查询分离**：SIM 卡管理不直接承担财务关账和账单审核职责。
4. **同时保留多个成本口径**：采购成本、消耗成本、分摊成本和闲置成本不得混为一个数值。
5. **按有效时间归属**：核算使用历史绑定和项目归属，不使用月末当前关系倒推整月费用。
6. **预估与结算分离**：账单到达前为预估或应计结果，完成对账关账后才是已结算成本。

## 3. 产品信息架构

```text
车辆管理
└── SIM 卡管理
    ├── SIM 卡台账
    └── 流量明细

费用管理
└── 流量费用
    ├── 资费与合同
    ├── 运营商账单
    ├── 成本核算
    └── 核算明细

数据分析
└── 流量成本分析
    ├── 用量与利用率
    ├── 项目/车辆/设备分析
    ├── 异常分析
    └── 套餐优化建议

车辆资产详情
└── 费用信息
    └── 流量费用
```

### 3.1 模块责任边界

| 模块 | 核心职责 | 不承担的职责 |
| --- | --- | --- |
| SIM 卡管理 | 卡片信息、终端/车辆绑定、原始用量、同步信息展示 | 财务结算、成本审批 |
| 费用管理 | 合同价格、账单、预核算、正式核算、分摊和对账 | 高频原始用量查询 |
| 数据分析 | 利用率、单位成本、趋势、异常和优化建议 | 修改合同、账单和已关账结果 |
| 车辆资产详情 | 展示归集到该车的费用并下钻 | 维护核算规则 |

## 4. SIM 卡管理设计

### 4.1 SIM 卡台账

继续作为 SIM 卡运营管理入口，支持查询卡片、套餐、当前周期用量、绑定车辆、终端和项目。

套餐、流量池和同步信息不设置独立管理页面，在 SIM 卡详情中以只读方式展示：

- 套餐名称、套餐额度、计费周期。
- 流量池编码、流量池类型、当前成员状态。
- 数据来源、最后同步时间、同步状态。
- 当前周期已用流量和数据更新时间。

外部物联网卡平台依然是套餐和流量池的权威数据源，车辆管理系统不提供重复编辑能力。

### 4.2 流量明细

流量明细用于查询单张 SIM 卡在指定时间范围内的日/月用量，定位用量异常。该页面不承担流量池经营分析和正式费用核算。

建议后续 PRD 明确：

- 单卡查询与左侧分组列表的交互关系。
- 日/月粒度、默认时间、最大查询范围和时区。
- 均值的计算对象、分母、展示位置和精度。
- 字节到 GB 的统一换算与舍入规则。
- 分页、空状态、加载失败、数据延迟和导出规则。

## 5. 流量费用的定义

“流量费用”不是单一费用，需要从费用构成、核算对象和成本口径三个维度定义。

### 5.1 费用构成

| 费用项 | 说明 |
| --- | --- |
| 单卡固定费 | 号码功能费、管理费、保号费等 |
| 套餐资源费 | 独立套餐或流量池的基础费用 |
| 套外流量费 | 超出套餐或流量池后的费用 |
| 加油包费用 | 临时购买流量包产生的费用 |
| 一次性费用 | 开卡、换卡、补卡等费用 |
| 调整金额 | 折扣、退款、补差和账单修正 |
| 税额 | 对接发票或财务入账时独立记录 |

### 5.2 核算对象

同一笔费用需支持沿以下链路查看和汇总：

```text
运营商/合同
  → 流量池
    → SIM 卡
      → 终端
        → 车辆或其他资产
          → 项目
```

系统应支持单卡、单终端、单车、项目、流量池和运营商等多个维度。

### 5.3 成本口径

| 口径 | 含义 | 主要用途 |
| --- | --- | --- |
| 采购成本 | 公司按合同或账单实际承担的费用 | 采购、财务对账 |
| 预估成本 | 账单到达前，根据资费规则和当前用量计算的费用 | 月中运营监控 |
| 消耗成本 | 按实际用量与标准单位成本折算的资源成本 | 使用效率分析 |
| 分摊成本 | 共享费用按规则分配到卡、资产或项目的成本 | 内部管理核算 |
| 闲置成本 | 已购买但未使用的流量资源成本 | 套餐优化 |
| 套外成本 | 超出基础额度而产生的额外成本 | 异常和风险管理 |

## 6. 核算公式与分摊规则

### 6.1 基础公式

```text
本期采购成本
= 套餐费用按期摊销
+ 单卡固定费
+ 流量包费用
+ 套外费用
+ 一次性费用
+ 调整金额

流量池利用率 = 实际使用量 ÷ 本期可用流量额度

标准单位流量成本 = 流量资源采购成本 ÷ 本期可用流量额度

实际有效单位成本 = 流量资源采购成本 ÷ 本期实际使用量

流量消耗成本 = 实际使用量 × 标准单位流量成本

闲置成本 = max(可用额度 - 实际使用量, 0) × 标准单位流量成本
```

年度套餐需根据服务生效时间摊销到月，不建议在采购当月一次性归集。

### 6.2 核算示例

某流量池当月采购成本为 1,000 元，可用额度为 1,000GB，实际使用 400GB：

- 流量池利用率：40%。
- 标准单位流量成本：1 元/GB。
- 实际有效单位成本：2.5 元/GB。
- 已消耗资源成本：400 元。
- 闲置资源成本：600 元。

实际有效单位成本随利用率下降而上升，可用于衡量采购浪费，但不建议直接作为单卡的唯一财务分摊单价。

### 6.3 单卡成本

```text
单卡总成本
= 单卡直接费用
+ 流量消耗成本
+ 闲置成本分摊
+ 套外成本
+ 一次性费用
+ 调整金额
```

分摊建议：

1. 单卡固定费和可明确识别的一次性费用直接归集到卡。
2. 流量消耗成本按实际使用量计算。
3. 闲置成本优先按项目采购或贡献的套餐额度分摊，避免全部转嫁给高用量项目。
4. 套外费用有明确责任卡或项目时直接归集；无法直接归属时按确认的分摊规则处理。
5. 无用量但产生固定费的卡，固定费仍归集至该卡和其成本承担项目。

### 6.4 单车成本

```text
单车流量费用
= 核算期内绑定该车的所有 SIM 卡固定费用
+ 流量资源分摊费用
+ 套外费用
+ 一次性费用
+ 调整金额
```

单车应汇总该车所有终端的 SIM 卡费用。例如自动驾驶机器人可同时存在 ADU、T-BOX 和摄像头等多张卡，页面需同时展示车辆合计和终端明细。

## 7. 数据与关系模型

### 7.1 核心关系

```text
SIM 卡
  → SIM 卡与终端绑定历史
  → 终端
  → 资产对象
  → 资产项目归属历史
```

资产对象不应只限于车辆，需预留以下类型：

- 车辆。
- 自动驾驶机器人。
- 固定摄像头。
- 对讲机。
- 其他网联终端。

### 7.2 必须保留的历史数据

| 历史数据 | 关键字段 |
| --- | --- |
| SIM 与终端绑定历史 | `sim_id`、`terminal_id`、`effective_from`、`effective_to` |
| 终端与资产绑定历史 | `terminal_id`、`asset_id`、`effective_from`、`effective_to` |
| 资产项目归属历史 | `asset_id`、`project_id`、`effective_from`、`effective_to` |
| SIM 套餐历史 | `sim_id`、`plan_id`、`effective_from`、`effective_to` |
| 流量池成员历史 | `pool_id`、`sim_id`、`effective_from`、`effective_to` |
| 资费规则版本 | 规则版本、生效时间、失效时间、变更人 |

当 SIM 卡在月中更换车辆或项目时，建议以日用量为基础按绑定有效时间分段归集。无法归属的费用进入“未绑定/未归属”池，不得丢失。

## 8. 费用核算与账单

### 8.1 账单是否必需

账单不是流量分析的前置条件，但是准确计算实际费用并完成财务对账的必要数据。

| 已获取数据 | 可计算结果 | 结果定位 |
| --- | --- | --- |
| 用量数据 | 流量、利用率 | 运营统计 |
| 用量＋套餐价格 | 预计成本、标准成本 | 预估 |
| 用量＋合同价格 | 应计成本 | 月中预核算 |
| 用量＋运营商账单 | 实际成本、分摊成本 | 正式核算 |
| 账单＋发票/付款数据 | 入账与付款核对 | 财务闭环 |

第一期可使用 Excel 导入运营商账单，后续再对接运营商账单接口或财务系统。

### 8.2 核算流程

```text
同步 SIM/套餐/流量池与日用量
  → 检查绑定和项目归属
  → 加载合同与资费规则
  → 执行月中预核算
  → 导入或同步运营商账单
  → 生成差异清单
  → 重新计算与财务确认
  → 月度关账
  → 发布单卡/资产/车辆/项目核算结果
```

核算单建议设置状态：待采集、待核算、核算中、待确认、已关账、核算失败。

已关账数据不应直接覆盖。后续修改需通过调整单或重开期间完成，并保留核算版本和操作日志。

### 8.3 对账平衡关系

```text
卡片分摊成本合计 + 未分摊成本 = 流量池成本

车辆成本合计 + 非车辆资产成本 + 未绑定成本
= 卡片成本合计

项目成本合计 + 未归属成本 = 全部核算成本

运营商账单金额 + 调整金额 = 最终入账金额
```

## 9. 核心页面设想

### 9.1 资费与合同

- 维护运营商、合同编号、有效期、结算周期和币种。
- 配置套餐费、固定费、套外单价、流量包和折扣等资费。
- 资费规则按版本和生效期管理，禁止覆盖历史价格。

### 9.2 运营商账单

- 支持 Excel 导入或接口同步。
- 展示账单周期、运营商、合同、总用量、总金额、税额和状态。
- 自动校验卡号、流量池、资费规则、用量和金额差异。
- 输出缺失映射、重复账单、金额差异和用量差异清单。

### 9.3 成本核算

- 按核算月份生成核算单。
- 执行数据完整性检查、试算、重算、确认和关账。
- 展示采购成本、预估成本、分摊成本、未分摊成本及账单差异。
- 支持下钻到核算明细和异常数据。

### 9.4 核算明细

建议字段包括：核算期、运营商、合同、流量池、IMSI、终端、VIN/资产编号、项目、实际用量、利用率、标准单位成本、实际有效单位成本、直接费用、消耗成本、闲置分摊、套外费用、调整金额、核算总成本和结算状态。

### 9.5 流量成本分析

页面建议展示：

- SIM 卡总数、套餐/流量池总额度、已用流量和利用率。
- 采购成本、已结算成本、闲置成本和套外成本。
- 标准单位成本和实际有效单位成本。
- 按运营商、套餐、流量池、项目、车辆、设备类型的统计与排名。
- 零流量、低利用率、接近套餐上限、超套餐、流量突增和长期停机仍产生费用等异常。
- 降档、升档、停卡、扩容、迁移和调整流量池等规则化建议。

所有指标、图表和异常数量应支持下钻到 SIM 卡或核算明细。

### 9.6 车辆费用信息

车辆资产详情中的“流量费用”建议展示：

- 车辆本期流量和同比/环比。
- 预估费用或已结算费用，并明确标识状态。
- 直接费用、消耗成本、闲置分摊、套外成本和调整金额。
- 按终端和 SIM 卡拆分的明细。
- 下钻至 SIM 卡流量明细和费用核算明细的入口。

## 10. 权限建议

| 角色 | 权限建议 |
| --- | --- |
| 管理员 | 查看全部数据，维护绑定、资费规则和核算配置 |
| SIM 卡运营人员 | 维护卡片与终端关系，查看用量及同步信息 |
| 财务人员 | 维护合同价格，导入账单，核算、确认和关账 |
| 项目经理 | 查看权限范围内项目、车辆和设备的用量与成本 |
| 管理层 | 查看全局流量成本、效率和优化分析 |

数据范围延续车辆管理系统的项目权限体系，资费规则、账单和全局单位成本等敏感数据需单独控制可见范围。

## 11. 异常与数据质量

核算前必须检查并展示以下异常：

- SIM 卡未绑定终端或资产。
- 终端或资产未归属项目。
- 同一时段存在重叠绑定。
- SIM 卡未匹配套餐、流量池或资费规则。
- 用量缺失、重复、负数或异常增长。
- 系统用量与运营商账单用量不一致。
- 预核算金额与账单金额超出配置阈值。
- 已停机、销号或库存卡仍产生用量或费用。

## 12. 分期建设建议

### 第一期：建立可核算的数据链路

- 完善 SIM 卡台账和单卡流量明细。
- 在 SIM 详情中只读展示套餐、流量池和同步信息。
- 建立 SIM、终端、资产和项目的有效期绑定历史。
- 建立资费规则和账单 Excel 导入。
- 实现月度预核算、正式核算、单卡/单车/项目明细和基础对账。

### 第二期：分析与风险识别

- 建设流量利用率和成本分析页面。
- 增加零流量、低利用率、超量和流量突增等异常。
- 实现车辆费用信息 Tab 及多维下钻。
- 完善账单差异处理和月度关账。

### 第三期：优化决策与系统对接

- 对接运营商账单接口、采购系统或财务系统。
- 实现用量和成本预测。
- 基于历史数据生成升档、降档、停卡和流量池调整建议。
- 评估套餐优化前后的预期节省金额和实际节省金额。

## 13. 待业务确认事项

1. 运营商能否提供套餐、流量池成员及其历史关系接口。
2. 运营商账单的实际字段、格式、出账时间和数据粒度。
3. 合同与资费数据由车辆管理系统维护，还是从采购/财务系统同步。
4. 闲置流量成本按采购申请项目、套餐额度还是其他规则分摊。
5. 共享流量池跨项目使用时，是否需要计算项目间的流量借用或交叉补贴。
6. 单卡固定费在月中转绑车辆或项目时，是按天、按用量还是按月末归属分摊。
7. 非车辆终端是否纳入本系统的资产与项目成本核算范围。
8. 财务核算是否需要区分含税、不含税、已开票和已付款口径。

## 14. 本次已确认决策

1. 流量池效率分析与单卡流量明细分开，放在“数据分析 > 流量成本分析”。
2. 不建设独立的“数据同步记录”页面。
3. 套餐、流量池、数据来源、同步时间和同步状态在 SIM 卡信息中只读查看。
4. 物联网卡平台作为 SIM 卡、套餐、流量池和原始用量的权威数据源。
5. 车辆管理系统负责车辆/资产关联、成本核算、费用归集和分析展示。
