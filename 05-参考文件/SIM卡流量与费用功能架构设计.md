| 项目 | 内容 |

| 所属系统 | 车辆管理系统 |
| 文档性质 | 产品与功能架构参考方案 |
| 版本 | V1.1 |
| 日期 | 2026-09-22 |

> 本文档用于明确 SIM 卡流量、流量费用和车辆成本之间的产品架构与核算口径，不替代后续正式 PRD。

## 1. 背景与目标

公司的车辆、自动驾驶机器人、对讲机、AI 摄像头等设备使用大量物联网 SIM 卡。当前 SIM 卡多采用公司统一采购和企业共享流量池模式，存在以下问题：

1. SIM 卡、终端、车辆与项目的关系未形成完整历史链路。
2. 单卡、单车和项目的实际流量消耗与成本不清晰。
3. 流量池充值成本与实际流量消耗存在差异，需通过实际单位流量成本进行归集。
4. 缺少外部充值费用、实际用量与车辆成本之间的对账闭环。

建设目标是形成“卡、量、价、车、项目”的完整链路，支持流量查询、利用率分析、费用核算、成本归集、对账和套餐优化。

## 2. 总体设计原则

1. **外部平台管资源**：物联网卡平台是 SIM 卡状态、套餐、流量池成员和原始用量的权威数据源。
2. **车辆系统管业务关系**：车辆管理系统负责 SIM 卡与终端、车辆、其他资产及项目的绑定关系。
3. **费用核算与运营查询分离**：SIM 卡管理不直接承担财务关账和账单审核职责。
4. **费用口径收敛**：本期只核算流量池组成 SIM 卡的月度充值费用，不另行考虑固定费、套外费、加油包、税费或其他费用。
5. **按有效时间归属**：核算使用历史绑定和项目归属，不使用月末当前关系倒推整月费用。
6. **预估与实际分离**：月度未结束时展示实时流量费用，月度结束后生成实际流量费用并关账。

| 模块      | 核心职责                     | 不承担的职责        |
| ------- | ------------------------ | ------------- |
| SIM 卡管理 | 卡片信息、终端/车辆绑定、原始用量、同步信息展示 | 财务结算、成本审批     |

| 数据分析    | 利用率、单位成本、趋势、异常和优化建议      | 修改充值费用、核算和已关账结果 |

## 4. SIM 卡管理设计

### 4.1 SIM 卡台账

继续作为 SIM 卡运营管理入口，支持查询卡片、套餐、当前周期用量、绑定车辆、终端和项目。

套餐、流量池和同步信息不设置独立管理页面，在 SIM 卡详情中以只读方式展示：

- 套餐名称、套餐额度、计费周期。
- 流量池编码、流量池类型、当前成员状态。
- 数据来源、最后同步时间、同步状态。
- 当前周期已用流量和数据更新时间。

外部物联网卡平台依然是套餐和流量池的权威数据源，车辆管理系统不提供重复编辑能力。

### 4.2 流量明细

流量明细用于查询单张 SIM 卡在指定时间范围内的日/月用量，定位用量异常。该页面不承担流量池经营分析和正式费用核算。

建议后续 PRD 明确：

- 单卡查询与左侧分组列表的交互关系。
- 日/月粒度、默认时间、最大查询范围和时区。
- 均值的计算对象、分母、展示位置和精度。
- 字节到 GB 的统一换算与舍入规则。
- 分页、空状态、加载失败、数据延迟和导出规则。

## 5. 流量费用的定义

本期流量费用只指流量池组成 SIM 卡的流量成本，不考虑单卡固定费、套外费、加油包、开卡费、税费、折扣和其他费用。

### 5.1 两种流量费用

| 费用名称 | 适用时机 | 计算公式 | 用途 |
| --- | --- | --- | --- |
| 实时流量费用 | 月度尚未结束 | 截至当前实际使用流量 × 预估单位流量成本 | 月中预估费用、运营监控 |
| 实际流量费用 | 月度结束后 | 当月实际使用流量 × 实际单位流量成本 | 月度结算、成本归集 |

月度结束后，实时流量费用应被实际流量费用替换，但需保留预估值、实际值和差异值供追溯。

### 5.2 费用核算对象

核算以流量池和月份为主要单元，同一流量池中组成该池的 SIM 卡共同分享单位流量成本。费用结果再沿以下链路下钻：

```text
外部充值费用来源
  → 流量池
    → SIM 卡
      → 终端
        → 车辆或其他资产
          → 项目
```

系统应支持流量池、单卡、单终端、单车和项目等多个查询维度，但只保留一套流量费用口径。

## 6. 核算公式与分摊规则

### 6.1 单位流量成本

```text
流量池月度充值费用总额
= 当月构成该流量池的所有 SIM 卡月度充值费用之和

流量池实际使用总量
= 当月流量池内所有 SIM 卡的实际使用流量之和

实际单位流量成本
= 流量池月度充值费用总额 ÷ 流量池实际使用总量

实时流量费用
= 截至当前的实际使用流量 × 预估单位流量成本

实际流量费用
= 当月实际使用流量 × 实际单位流量成本

流量使用率
= 实际使用流量 ÷ 外部平台提供的当月可用流量额度
```

实时费用的预估单位流量成本建议默认取该流量池最近一个已关账月份的实际单位流量成本；如无历史结果，由财务或管理员录入本月预估单价。预估单价需保留版本和来源。

单位流量成本的分母一律为实际已使用的流量总量，不使用套餐额度或流量池总额度作为实际单位成本的分母。

### 6.2 核算示例

某流量池当月组成 SIM 卡的充值费用合计为 1,000 元，当月实际使用总量为 400GB：

- 实际单位流量成本：2.5 元/GB。
- 若月中预估单位流量成本为 2.0 元/GB，当月累计使用 200GB，则实时流量费用为 400 元。
- 月度结束后，实际流量费用为 400GB × 2.5 元/GB = 1,000 元。

在实际使用总量大于 0 时，实际流量费用在流量池层面与当月充值费用总额一致；在卡、终端、车辆和项目层面按各自实际用量占比分配。

### 6.3 单卡、单车与项目分配

```text
单卡实时流量费用
= 该卡当月截至当前实际使用量 × 流量池预估单位流量成本

单卡实际流量费用
= 该卡当月实际使用量 × 流量池实际单位流量成本

单车/项目流量费用
= 所属车辆/项目下所有 SIM 卡实际流量费用之和
```

分配必须使用流量池和 SIM 卡的月度成员快照，并根据 SIM 卡、终端、车辆和项目的有效时间归属。不再额外分摊固定费、闲置成本或其他费用。

如流量池月度实际使用总量为 0，实际单位流量成本无法计算。系统不应自动设为 0 元/GB，应标记为“无法核算”，将该流量池的充值费用保留为待处理数据。

## 7. 数据与关系模型

### 7.1 核心关系

```text
SIM 卡
  → SIM 卡与终端绑定历史
  → 终端
  → 资产对象
  → 资产项目归属历史
```

资产对象不应只限于车辆，需预留以下类型：

- 车辆。
- 自动驾驶机器人。
- 固定摄像头。
- 对讲机。
- 其他网联终端。

### 7.2 必须保留的历史数据

| 历史数据 | 关键字段 |
| --- | --- |
| SIM 与终端绑定历史 | `sim_id`、`terminal_id`、`effective_from`、`effective_to` |
| 终端与资产绑定历史 | `terminal_id`、`asset_id`、`effective_from`、`effective_to` |
| 资产项目归属历史 | `asset_id`、`project_id`、`effective_from`、`effective_to` |
| SIM 套餐历史 | `sim_id`、`plan_id`、`effective_from`、`effective_to` |
| 流量池成员历史 | `pool_id`、`sim_id`、`effective_from`、`effective_to` |
| 流量池月度充值费用 | `pool_id`、`年月`、`sim_id`、`充值费用`、`导入批次` |
| 流量池月度用量快照 | `pool_id`、`年月`、`实际使用总量`、`数据截止时间` |
| 预估单位流量成本 | `pool_id`、`年月`、`预估单价`、`来源`、`版本` |

当 SIM 卡在月中更换车辆或项目时，建议以日用量为基础按绑定有效时间分段归集。无法归属的费用进入“未绑定/未归属”池，不得丢失。

## 8. 费用核算与外部费用导入

### 8.1 外部充值费用是否必需

流量用量和利用率分析不依赖充值费用；但是实际单位流量成本和实际流量费用必须有当月外部导入的流量池充值费用。

| 已获取数据 | 可计算结果 | 结果定位 |
| --- | --- | --- |
| 流量使用量 | 流量、利用率 | 运营统计 |
| 流量使用量＋预估单价 | 实时流量费用 | 月中预估 |
| 流量使用量＋当月充值费用 | 实际单位成本、实际流量费用 | 月度结算 |

外部导入明细建议包含：流量池编码、年月、SIM 标识、该卡当月充值费用、数据来源和导入批次。导入后按流量池和年月汇总，不再额外维护合同价格或其他费用。

### 8.2 核算流程

```text
同步 SIM/套餐/流量池与日用量
  → 检查绑定和项目归属
  → 导入当月流量池组成 SIM 卡的充值费用
  → 配置或读取当月预估单位流量成本
  → 更新实时流量费用
  → 月度结束后计算实际单位流量成本
  → 生成实际流量费用并执行校验
  → 月度关账
  → 发布单卡/资产/车辆/项目核算结果
```

核算单建议设置状态：待采集、待核算、核算中、待确认、已关账、核算失败。

已关账数据不应直接覆盖。后续修改需通过调整单或重开期间完成，并保留核算版本和操作日志。

### 8.3 校验与平衡关系

```text
流量池当月实际使用总量 = 流量池内所有 SIM 卡实际使用量之和

流量池实际单位流量成本 × 实际使用总量
= 流量池当月充值费用总额

单卡实际流量费用合计 + 未绑定/未归属费用
= 流量池实际流量费用

车辆/项目实际流量费用合计
= 其归属 SIM 卡实际流量费用合计
```

## 9. 核心页面设想

### 9.1 流量池充值费用导入

- 支持导入外部提供的流量池成员 SIM 卡月度充值明细。
- 导入字段至少包括：流量池编码、年月、SIM 标识、月度充值费用、数据来源、导入批次。
- 按流量池和年月防止重复导入，允许在未关账时间重新导入并保留历史批次。
- 导入后自动汇总流量池月度充值费用总额。

### 9.2 流量费用核算

- 按流量池和月份生成核算单。
- 月度未结束时展示实时流量费用；月度结束后计算实际单位流量成本和实际流量费用。
- 预估单价默认使用最近一个已关账月份的实际单价，无历史时支持手工录入。
- 展示预估值、实际值、单位成本、差异值和数据状态。
- 支持预计、重算、关账，已关账数据不直接覆盖。

### 9.3 核算明细

建议字段包括：核算期、流量池、IMSI、终端、VIN/资产编号、项目、截至当前用量、当月实际用量、流量使用率、预估单位流量成本、实时流量费用、实际单位流量成本、实际流量费用和结算状态。

### 9.4 流量成本分析

页面建议展示：

- SIM 卡总数、流量池实际使用总量、当月可用流量额度和流量使用率。
- 当月充值费用总额、实时流量费用和实际流量费用。
- 预估单位流量成本和实际单位流量成本。
- 按运营商、套餐、流量池、项目、车辆、设备类型的统计与排名。
- 零流量、低利用率、流量突增和实时费用超预估等异常。
- 低利用率流量池、流量突增卡和实时费用超预估等异常。

所有指标、图表和异常数量应支持下钻到 SIM 卡或核算明细。

### 9.5 车辆费用信息

车辆资产详情中的“流量费用”建议展示：

- 车辆本期流量和同比/环比。
- 实时流量费用或实际流量费用，并明确标识月度状态。
- 截至当前用量、当月实际用量、预估单价和实际单价。
- 按终端和 SIM 卡拆分的明细。
- 下钻至 SIM 卡流量明细和费用核算明细的入口。

## 10. 权限建议

| 角色 | 权限建议 |
| --- | --- |
| 管理员 | 查看全部数据，维护绑定、预估单价和核算配置 |
| SIM 卡运营人员 | 维护卡片与终端关系，查看用量及同步信息 |
| 财务人员 | 导入流量池充值费用，录入或确认预估单价，核算、确认和关账 |
| 项目经理 | 查看权限范围内项目、车辆和设备的用量与成本 |
| 管理层 | 查看全局流量成本、效率和优化分析 |

数据范围延续车辆管理系统的项目权限体系，充值费用导入、预估单价和全局单位成本等敏感数据需单独控制可见范围。

## 11. 异常与数据质量

核算前必须检查并展示以下异常：

- SIM 卡未绑定终端或资产。
- 终端或资产未归属项目。
- 同一时段存在重叠绑定。
- SIM 卡当月未匹配流量池成员快照。
- 用量缺失、重复、负数或异常增长。
- 系统用量与外部导入用量不一致。
- 流量池未导入当月充值费用。
- 流量池实际使用总量为 0，无法计算实际单位流量成本。
- 预估单位流量成本缺失或来源未确认。
- 已停机、销号或库存卡仍产生用量。

## 12. 分期建设建议

### 第一期：建立可核算的数据链路

- 完善 SIM 卡台账和单卡流量明细。
- 在 SIM 详情中只读展示套餐、流量池和同步信息。
- 建立 SIM、终端、资产和项目的有效期绑定历史。
- 建立流量池充值费用 Excel 导入和预估单价配置。
- 实现月度预核算、正式核算、单卡/单车/项目明细和基础对账。

### 第二期：分析与风险识别

- 建设流量利用率和成本分析页面。
- 增加零流量、低利用率、超量和流量突增等异常。
- 实现车辆费用信息 Tab 及多维下钻。
- 完善充值费用差异处理和月度关账。

### 第三期：优化决策与系统对接

- 对接外部充值费用接口、采购系统或财务系统。
- 实现用量和成本预测。
- 基于历史数据生成升档、降档、停卡和流量池调整建议。
- 评估套餐优化前后的预期节省金额和实际节省金额。

## 13. 待业务确认事项

1. 外部充值费用导入的最终字段、格式、出账时间和数据粒度。
2. 预估单位流量成本是否统一使用最近已关账月份的实际单价，无历史时的录入权限和审批规则。
3. 流量池实际使用总量为 0 时，充值费用是否进入待处理池，以及由谁确认。
4. 流量池成员在月中变更时，当月充值费用归属是按月度快照还是按日分段。
5. 非车辆终端是否纳入本系统的资产与项目流量费用归集范围。

## 14. 本次已确认决策

1. 流量池效率分析与单卡流量明细分开，放在“数据分析 > 流量成本分析”。
2. 不建设独立的“数据同步记录”页面。
3. 套餐、流量池、数据来源、同步时间和同步状态在 SIM 卡信息中只读查看。
4. 物联网卡平台作为 SIM 卡、套餐、流量池和原始用量的权威数据源。
5. 车辆管理系统负责车辆/资产关联、成本核算、费用归集和分析展示。
6. 流量费用只包含实时流量费用和实际流量费用，不另行考虑其他费用。
7. 实时流量费用使用实际使用量乘以预估单位流量成本。
8. 实际流量费用使用实际使用量乘以实际单位流量成本；实际单位流量成本的分母是流量池当月实际使用总量。
9. 实际单位流量成本的分子是外部导入的流量池组成 SIM 卡的月度充值费用之和。
