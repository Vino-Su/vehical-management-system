# 车辆管理系统

## 项目简介

车辆管理系统是一个面向企业车辆资产管理的前端原型系统，涵盖车辆全生命周期管理。系统采用纯 HTML/CSS/JavaScript 实现，可作为前端高保真原型或后续前后端分离开发的基础模板。

系统采用“顶部一级模块 + 左侧二三级导航”结构：车辆管理、运行监管、维保管理、合规与风险、费用管理、退出管理、数据分析、系统管理八个一级模块位于顶部；侧栏随一级模块切换，并支持收起为 64px 图标栏。

## 功能模块

### 1. 车辆建档
- **列表页**：支持多维度查询筛选（车架号、车牌号、车型名称、车辆状态等），分页展示车辆建档数据，支持批量导入、单条录入、数据导出。
- **新增页**：完整的新车信息录入表单，涵盖车辆基础信息、归属信息、车辆照片、行驶证信息、车型信息、硬件与SIM关联、车辆功能配置及备注。
- **详情页**：车辆档案详情展示（预留入口，联动资产管理模块）。

### 2. 车辆资产管理
- **列表页**：车辆资产全量列表，支持车辆分配、编辑、删除、导出等操作，多条件组合查询。
- **详情页**：单车360度档案，采用“车辆总览、运行监控、车辆档案、业务记录、生命周期、变更日志”六个一级Tab；车辆全局信息区与Tab吸顶固定；车辆总览由运行总账指标条（累计里程、累计费用、车龄，费用附统计口径说明）与当班决策看板（作业可用性、实时运行、当班保障、健康与损耗、合规与风险、当前提醒）构成；车辆档案提供查看态/编辑态共用的分组目录快速定位；业务记录下汇总调度、售后维保、BOM、合规与风险和费用；生命周期以只读时间线汇总建档、关键信息变更、完成态维保与调度、故障、合规、风险及退出处置事件，支持分类/时间筛选和来源详情追溯。

### 3. 车型管理
- **列表页**：车型主数据管理，支持可折叠展开的版本子列表，涵盖详情、编辑、新建版本、删除等操作。
- **新增页**：新建车型基础信息及首个版本信息。
- **详情页**：车型及版本信息详情查看与编辑。
- **新建版本页**：基于已有版本快速新建车型版本，继承原有参数并支持修改。

### 4. 车辆标签管理
- **标签管理列表页**：以两级树形结构（标签组+子标签）展示标签，支持公有/私有区分、新建/编辑/删除、查看标签下车辆、批量移入/移出。
- **车辆资产管理联动**：资产管理列表页支持按标签筛选、标签列展示、批量打标签/移出标签；详情页基础信息支持单车标签管理。
- 标签与车辆为多对多关系，不影响车辆状态与归属项目等既有业务字段。
- 详细设计见《标签管理PRD》。

### 5. 车辆调度管理
- **可用车辆库列表页**：展示在库-闲置可调出车辆，支持多条件查询、新增调度申请、导出。
- **调度记录管理列表页**：调度任务全流程管理（新建/编辑/提交/撤回/再次提交/删除/导出），支持出库审批、交接审批。
- **调度申请详情页**：三环节步骤条（申请→出库→交接）与流程日志，按状态提供对应操作按钮。
- 详细设计见《调度管理PRD》。

### 6. SIM 卡管理
- **SIM 卡台账列表页**：支持 SIM 卡、套餐、用量、车辆及终端等多条件筛选，并支持选择数据或按当前条件导出。
- **SIM 卡详情页**：展示基本信息、计费周期、终端信息、日/月流量统计及可分页的历史绑定记录。
- **信息维护页**：支持 VIN 码和车牌号双向联动，按选定车辆选择终端硬件；保存后自动记录绑定历史。
- **SIM 卡流量明细页**：左侧支持按运营商、套餐或项目分组检索 SIM 卡，右侧按单卡查询日/月流量，支持分页选择与导出。
- **车辆流量明细页**：左侧支持按项目或车型分组检索车辆，右侧汇总车辆关联全部 SIM 卡的日/月流量，支持分页选择与导出。
- 详细设计见《SIM卡管理PRD》。

### 7. 能耗费用台账
- **加油费用明细台账**：支持按加油时间、车牌号、关联油卡、上报人筛选，展示油量、单价、金额、油卡余额、里程及凭证；支持新增、编辑、详情、变更记录、删除、导入导出与分页。
- **加水费用明细台账**：支持按加水时间、车牌号、上报人筛选，覆盖月付、现金及线上支付场景；支持新增、编辑、详情、变更记录、删除、导入导出与分页。
- **充电费用明细台账**：支持按充电开始时间、车牌号、上报人筛选，展示时长、度数、电费、服务费、金额、里程及充电明细；支持新增、编辑、详情、变更记录、删除、导入导出与分页。

### 8. 车辆实时监管
- **车辆监管一张图**：基于 Leaflet + OpenStreetMap 的车辆地图监管，默认按市聚合；地图右上角以搜索/筛选图标按需展开精确搜索和项目/区域/车型多选下拉筛选；左侧车辆列表、异常与故障两个 Tab 仅保留项目/车型/区域分组，并与地图条件联动；支持紧凑车辆详情弹窗、故障异常角标、原地图窗口内轨迹回放控制台和视频弹窗，轨迹回放可按日期、时段、车辆查询并支持播放暂停、倍速、拖动时间轴和状态联动。
- **车辆运行数据**：左侧按项目或车型分组查询并选择车辆，右侧按采集时间查看终端上报的位置、驾驶、车辆姿态、作业模式及在线状态数据，支持分页选择与导出。
- **车辆故障信息**：按车辆标识、项目、故障码和上报时间查询车辆主动上报的软硬件故障，支持分页选择与导出。
- **车辆异常记录**：展示策略规则触发的超时停靠、超速行驶和限行区行驶记录，支持组合查询、分页选择与导出。
- 详细设计见《车辆实时监管PRD》。

## 公共组件（components/）

| 组件 | 文件 | 说明 |
|:---|:---|:---|
| 设计令牌 | `common.css` | 颜色、字号、圆角、间距变量，严格对齐 UI 设计规范 |
| 布局框架 | `common.css` | 64px 顶部一级模块导航 + 224px 二三级侧栏（可收起至 64px）+ 主内容区（padding 24px） |
| 按钮 | `common.css` | `.btn`（32px）、`.btn-primary`、`.btn-danger`、`.btn-sm`（24px）、`.btn-link` |
| 表格 | `common.css` | `.table-wrapper`（横向滚动）、48px 行高、`.col-left/.col-center/.col-right` 对齐类、`.ellipsis`、`.num` |
| 固定列长表格 | `fixed-table.css` + `fixed-table.js` | 在 `.table-wrapper` 增加 `.fixed-table`，用 `data-fixed-first` / `data-fixed-last` 固定首个业务列和末列，自动跳过复选框；单元格不换行，`data-fixed-min-width` 指定横向滚动阈值 |
| 标签 | `common.css` | `.tag` 及 `.tag-blue/green/orange/red/default/purple/yellow` |
| 分页 | `pagination-component.js` + `common.js` | 公共 `Pagination` 组件统一渲染页码、每页条数与翻页状态；`Common.renderPagination()` 保持旧页面调用兼容 |
| 查询筛选 | `filter-component.js` | 统一处理历史查询栏及子页面查询区的展开/收起，超过一行时自动收纳多余条件 |
| 弹窗 | `common.css` + `common.js` | `.modal-overlay/.modal-box`（600px）与 `.modal-box--lg`（800px）；`Common.openModal/closeModal/confirm` |
| Toast | `common.js` | `Common.showToast(msg, type)` |
| 表单 | `form.css` | `.form-row`（标签左置外置）、`.field-error`（控件下方红字）、`.form-grid` |
| 顶部导航 / 侧边栏 | `common.js` | `Common.initLayout()` 按 `activeMenuId` 自动定位一级模块；切换模块默认进入首个可访问页面，渲染二三级菜单并记忆侧栏收起状态 |

## 使用方式

1. 克隆或下载本项目到本地。
2. 直接用浏览器打开根目录的 `index.html`（会自动跳转到 `03-高保真页面/index.html` 页面索引）。
3. 在页面索引中点击任意模块/页面即可预览。

> 说明：本系统为纯前端静态页面，数据为本地模拟数据，无需后端服务即可运行预览。
> 已适配 GitHub Pages：开启 Pages 后访问仓库根地址即可打开页面索引；所有页面均使用相对路径，可脱离服务器直接双击打开。

## 技术说明

- **技术栈**：HTML5 + CSS3 + 原生 JavaScript（无框架依赖，无任何 CDN / 外部资源）。
- **布局方案**：顶部固定 64px 一级模块导航；左侧二三级侧栏默认 224px、可收起至 64px；主内容区自动填充剩余空间。
- **公共组件**：见上方「公共组件」表。
- **UI 设计规范**：所有页面严格遵循 `.claude/UI_design_WEB.md`，包括设计令牌、字号层级、8px 间距体系、表格对齐规则、弹窗按钮布局等。
  - 注：该规范「技术栈」条款要求 Tailwind CSS v3，本项目实际采用**手写 CSS + 设计令牌变量**实现同等视觉与交互效果，以避免对既有页面的大规模重写；此为已知的有意偏离。
- **浏览器兼容**：推荐 Chrome / Edge 等现代浏览器；已在 1366×768 与 1920×1080 下验证。
