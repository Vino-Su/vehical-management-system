## 名词解释

| 名词/缩写 | 解释 |
| ---------- | ---- |
| 设备 | 安装在车辆上的车端网联终端，包含 T-Box、ADU、OBU、DTU、视频盒子五类 |
| 设备识别码 | 设备的全局唯一业务标识，是设备台账与绑定关系的锚点 |
| 绑定关系 | 设备与车辆、设备与 SIM 卡之间的当前关联关系，支持解绑并保留历史 |
| 无分组 | 按当前分组维度缺少对应属性值的设备所归集的分组，仅按「车辆VIN码」或「项目」分组时可能出现 |
| VIN 码 | 车辆识别代号，车辆唯一标识 |
| IMSI | 国际移动用户识别码，SIM 卡唯一标识 |

## 1. 业务背景与使用角色

### 1.1 业务背景
- 模块定位：设备管理是车端网联终端的主数据台账，独立维护设备自身信息，并承载设备与车辆、SIM 卡的当前绑定关系。
- 核心特点：设备是独立于车辆的业务对象，与车辆为「一车多终端」关系；绑定关系随时点变化并全程留痕，换绑不重建设备台账。
- 关联模块关系：设备绑定车辆后经 VIN 码关联车辆资产与归属项目；设备绑定 SIM 卡后经 IMSI 关联 SIM 卡台账与流量费用；设备字段与车辆档案「硬件信息」表对齐。
- 业务痛点：终端信息原先随车辆档案维护，无法统一管理备件终端、换绑与一车多终端场景，终端与车辆、SIM 卡的对应关系缺少可追溯的台账。

### 1.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 管理员 | 维护设备主数据、维护设备与车辆和 SIM 卡的绑定关系、查询与导出设备台账、查看设备详情 | WEB |
| 项目经理 | 查询与导出设备台账、查看设备详情 | WEB |

本期为静态高保真原型，使用 mock 数据，不实现按项目的数据权限控制与真实文件导出；登录后统一具备上述表格中角色的操作能力。

### 1.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 终端可查 | 设备信息集中登记，支持按设备类型、车辆、项目分组快速定位单个终端 |
| 关系可溯 | 设备与车辆、SIM 卡的绑定与解绑全部留痕，可回溯历史变更 |
| 口径统一 | 设备字段与车辆档案「硬件信息」表对齐，避免同一份信息多处维护造成差异 |

## 3. 功能详细设计

### 3.1 F01 设备台账浏览与检索

#### 3.1.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 从分组维度与检索条件两个方向快速定位目标设备，查看其台账信息并导出 |
| 使用角色 | 管理员、项目经理 |
| 触发条件 | 进入「车辆管理 / 设备管理」菜单，或需要按设备类型、车辆、项目核对终端 |
| 功能边界 | 包含分组浏览、识别码检索、条件筛选、分页、导出与行内操作入口；不包含设备新增编辑与绑定关系维护本身 |
| 成功结果 | 定位到目标设备或设备集合，并可导出当前结果 |

#### 3.1.3 数据与字段规则

**输入与查询条件：**

| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | -------------------- | ------ | ------------- |
| 设备识别码 | 左栏检索条件 | 手工输入 | 空 | 对设备识别码模糊匹配，不区分大小写 |
| 是否有SIM卡 | 右栏筛选条件 | 下拉单选 | 全部 | 枚举值：有、无 |
| 状态 | 右栏筛选条件 | 下拉单选 | 全部 | 枚举值：正常、维修中、已报废 |
| 分组维度 | 左栏分组方式 | 单选切换 | 按设备类型 | 枚举值：设备类型、车辆VIN码、项目 |

**展示与输出字段：**

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 设备名称 | 设备台账名称 | 设备主数据 | — | 显示「—」 |
| 设备类型 | 设备分类 | 设备主数据 | 枚举值：T-Box、ADU、OBU、DTU、视频盒子 | — |
| 设备识别码 | 设备唯一标识 | 设备主数据 | — | — |
| 车辆VIN码 | 当前绑定车辆 | 绑定关系 | 提供跳转车辆资产详情入口 | 显示「未绑定车辆」 |
| 是否有SIM卡 | 当前是否绑定 SIM 卡 | 绑定关系 | 由 IMSI 是否为空判定 | 显示「无」 |
| IMSI | 当前绑定的 SIM 卡标识 | 绑定关系 | 提供跳转 SIM 卡详情入口 | 显示「未绑定」 |
| 厂商 / 型号 | 设备厂商与型号 | 设备主数据 | 两项拼接展示 | 显示「—」 |
| 状态 | 设备状态 | 设备主数据 | 枚举值：正常、维修中、已报废 | — |
| 最近维护 | 最后一次变更时间 | 系统写入 | 精确到分钟 | — |
| 组内数量 | 当前分组内设备台数 | 系统统计 | 跟随检索与分组维度实时计算 | — |

#### 3.1.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R01 | 页面加载 | 左栏默认按设备类型分组，默认选中「全部设备」，仅展开排序最前的分组，其余分组收起 | 右栏展示全部设备的第一页 |
| R02 | 切换分组维度 | 保持当前浏览范围；若当前选中的是某个分组，则收敛为该分组内排序最前的设备 | 按新维度重新分组，恢复仅展开首个分组 |
| R03 | 选中左栏设备 | 右栏收敛到该设备，并自动展开该设备所在分组 | 右栏分页重置到第 1 页，已勾选清空 |
| R04 | 选中左栏分组或「全部设备」 | 右栏收敛到该分组内全部设备或全部设备，被选中的分组自动展开 | 右栏分页重置到第 1 页，已勾选清空 |
| R05 | 分组属性为空 | 归入「无分组」，且「无分组」固定排在所有分组之后 | — |
| R06 | 左栏检索后当前选中项失效 | 自动收敛为检索结果中排序最前的设备 | 右栏同步收敛 |
| R07 | 右栏任一查询条件变化 | 右栏结果 = 左栏选择范围 ∩ 右栏筛选条件 | 分页重置到第 1 页，已勾选清空 |
| R08 | 排序规则 | 当前选中项所在的组或设备置首；其余按名称排序；「无分组」始终置末 | — |

#### 3.1.5 交互流程

1. 用户进入设备管理页，系统加载设备台账并按设备类型分组，默认选中「全部设备」，右栏展示全部设备的第一页。
2. 用户在左栏检索框输入设备识别码并点击「查询」或回车，左栏仅展示匹配设备并重新分组；点击「重置」恢复全部设备。
3. 用户点击左栏分组行，右栏展示该分组内全部设备；点击分组行左侧箭头仅折叠或展开该分组，不改变右栏结果。
4. 用户点击左栏某台设备，右栏收敛到该设备并自动展开其所在分组。
5. 用户点击「全部设备」，右栏恢复到全部设备。
6. 用户在右栏选择是否有SIM卡、状态后点击「查询」，右栏在左栏选择范围内进一步筛选；点击「重置」清空右栏条件。
7. 用户翻页或调整每页条数，表格展示对应数据。
8. 用户点击「导出」处理结果：
   - 已有勾选 → 导出勾选的设备
   - 无勾选 → 导出当前右栏筛选结果的全部设备
   - 当前无数据 → 提示无内容可导出，不生成文件

#### 3.1.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 左栏无匹配设备 | 识别码检索无结果 | 左栏展示空态，右栏同步无数据 | 提示未找到匹配的设备 | 点击「重置」或修改检索条件 |
| 右栏无匹配记录 | 左栏选择范围与右栏筛选取交集后为空 | 表格展示空态 | 提示暂无匹配设备，引导调整左侧分组或筛选条件 | 调整左栏选择或右栏条件 |
| 导出无内容 | 当前无数据 | 不生成导出文件 | 提示当前没有可导出的设备 | 调整条件后重试 |

### 3.2 F02 设备主数据维护

#### 3.2.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 建立与更新设备主数据，保证设备识别码唯一 |
| 使用角色 | 管理员 |
| 触发条件 | 新终端入库需要登记，或设备信息发生变化需要更正 |
| 功能边界 | 仅维护设备自身字段；设备与车辆、SIM 卡的关系在绑定关系维护中处理 |
| 成功结果 | 设备写入台账并刷新列表；新增后自动定位到该设备 |

#### 3.2.3 数据与字段规则

| 字段 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| ---- | -------- | -------------------- | ------ | ------------- |
| 设备名称 | 设备台账名称 | 手工输入 | 空 | 必填 |
| 设备类型 | 设备分类 | 下拉单选 | 空 | 必填；枚举值：T-Box、ADU、OBU、DTU、视频盒子 |
| 设备识别码 | 设备唯一标识 | 手工输入 | 空 | 必填；全局唯一，不区分大小写 |
| 设备序列号 | 厂商序列号 | 手工输入 | 空 | 选填 |
| 厂商 | 设备厂商 | 手工输入 | 空 | 选填 |
| 型号 | 设备型号 | 手工输入 | 空 | 选填 |
| 状态 | 设备状态 | 下拉单选 | 正常 | 枚举值：正常、维修中、已报废 |
| 备注 | 补充说明 | 手工输入 | 空 | 选填 |

#### 3.2.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R09 | 提交保存 | 设备名称、设备类型、设备识别码为必填，任一为空不允许保存 | — |
| R10 | 提交保存 | 设备识别码与既有设备重复时阻断保存 | 表单数据保留，不写入台账 |
| R11 | 新增保存成功 | 自动定位到新增设备，并刷新左栏分组与计数 | 左栏检索条件清空，右栏收敛到该设备 |
| R12 | 编辑保存成功 | 保持当前浏览范围，仅刷新数据 | 右栏分页回到第 1 页，已勾选清空 |

#### 3.2.5 交互流程

1. 用户点击「新增设备」，或在设备行点击「编辑」，系统打开设备表单；编辑态回填现有设备数据。
2. 用户填写或修改字段后点击保存。
3. 处理结果：
   - 成功 → 写入设备台账 + 刷新左栏分组与右栏列表 + 提示新增或更新成功 + 可继续编辑或维护绑定关系
   - 失败 → 提示具体失败原因（必填项缺失、识别码已存在）+ 表单数据保留 + 用户修改后可重新保存

### 3.3 F03 绑定关系维护

#### 3.3.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 维护设备与车辆、SIM 卡的当前绑定关系，并保留变更历史 |
| 使用角色 | 管理员 |
| 触发条件 | 设备安装到车辆、更换车辆、装配或更换 SIM 卡、设备退役解绑 |
| 功能边界 | 只维护当前绑定关系，不维护车辆主数据与 SIM 卡主数据；历史记录只读 |
| 成功结果 | 绑定关系更新，台账与详情同步刷新，并写入一条绑定或解绑历史 |

#### 3.3.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 管理员 | 绑定、解绑、更换设备所关联的车辆与 SIM 卡 | 全部设备 | 设备已登记在台账中 |
| 项目经理 | 无绑定维护入口，仅可查看当前绑定与历史 | 全部设备 | — |

#### 3.3.3 数据与字段规则

| 字段 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| ---- | -------- | -------------------- | ------ | ------------- |
| 绑定车辆 | 设备当前安装的车辆 | 车辆资产列表下拉单选 | 当前绑定车辆 | 可清空以解除绑定 |
| 绑定 SIM 卡 | 设备当前关联的 SIM 卡 | SIM 卡台账下拉单选 | 当前绑定 SIM 卡 | 可清空以解除绑定；已被其他设备占用的 SIM 卡标记占用设备并不可选 |

#### 3.3.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R13 | 保存绑定 | 同一张 SIM 卡同一时间只能绑定一个设备，已被占用的 SIM 卡不可选中 | 阻断占用冲突的保存 |
| R14 | 保存绑定 | 清空车辆或 SIM 卡即为解除对应绑定关系 | 写入一条解绑历史 |
| R15 | 保存绑定 | 车辆、SIM 卡两项各自发生变化时分别写入历史，记录变更时间、操作类型与变更说明 | 绑定维护历史倒序追加 |
| R16 | 保存绑定 | 绑定不改变设备状态，仅更新最近维护时间 | 刷新右栏列表；按车辆VIN码或项目分组时分组随之变化 |

#### 3.3.5 交互流程

1. 用户在设备台账行内或设备详情页点击「绑定」，系统打开维护绑定关系弹窗并回填当前绑定的车辆与 SIM 卡。
2. 用户选择绑定车辆与绑定 SIM 卡，可清空任一项以解绑，随后点击保存。
3. 处理结果：
   - 成功 → 更新当前绑定关系 + 写入绑定或解绑历史 + 刷新台账与左栏分组 + 提示绑定关系已保存
   - 失败 → 提示该 SIM 卡已绑定其他设备及其识别码 + 弹窗与已选内容保留 + 用户可重新选择后保存

### 3.4 F04 设备详情查看

#### 3.4.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 查看单台设备的完整信息、当前绑定关系与绑定维护历史 |
| 使用角色 | 管理员、项目经理 |
| 触发条件 | 在设备台账行内点击「查看」 |
| 功能边界 | 只读展示；编辑设备与维护绑定在详情页顶部提供入口，复用 F02、F03 的能力 |
| 成功结果 | 展示设备信息、当前绑定信息与绑定维护历史 |

#### 3.4.5 交互流程

1. 用户在设备台账点击「查看」，系统进入设备详情页。
2. 系统按设备识别码加载并展示设备信息、当前绑定与绑定维护历史：
   - 存在历史记录 → 按时间倒序展示绑定与维护记录
   - 无历史记录 → 提示暂无绑定与维护记录
3. 用户可经车辆 VIN 码跳转车辆资产详情、经 IMSI 跳转 SIM 卡详情，或点击「编辑设备」「维护绑定」执行维护操作，操作后详情页同步刷新。

## 4. 业务规则汇总

### 4.1 唯一性规则
- 设备识别码全局唯一，新增与编辑时均校验，不区分大小写。
- 同一张 SIM 卡在同一时间只能绑定一个设备，绑定保存时校验。
- 设备与车辆为「一车多终端」关系，同一车辆可绑定多台设备，不设唯一性约束。

### 4.3 状态流转
设备状态枚举值：正常、维修中、已报废。状态由人工在设备表单中直接维护，不限制状态之间的互转，也不驱动车辆状态或其他模块数据的变化。

### 4.4 字段联动规则

| 触发字段 | 触发条件 | 联动行为 |
| -------- | -------- | -------- |
| 绑定车辆 | 变更设备绑定的车辆 | 按「车辆VIN码」或「项目」分组时，设备所在分组随之变化 |
| 绑定 SIM 卡 | 变更设备绑定的 SIM 卡 | 「是否有SIM卡」与「IMSI」两列同步反映最新绑定 |
| 设备类型 | 新增或编辑时变更 | 按「设备类型」分组时，设备所在分组随之变化 |

### 4.6 校验规则

| 场景 | 校验项 | 处理 |
| ---- | ------ | ---- |
| 保存设备 | 设备名称、设备类型、设备识别码必填 | 阻断保存并提示缺失项 |
| 保存设备 | 设备识别码全局唯一 | 阻断保存并提示识别码已存在 |
| 保存绑定 | SIM 卡当前未被其他设备占用 | 阻断保存并提示占用设备识别码 |

### 4.9 变更日志记录规则
设备的新增、编辑、绑定与解绑均写入绑定与维护历史，记录操作时间、操作类型（新增设备、编辑设备、绑定车辆、解绑车辆、绑定 SIM、解绑 SIM）与变更说明，按时间倒序展示，写入后不可修改。

## 5. 关联模块说明

| 关联模块 | 关联关系 | 说明 |
| -------- | -------- | ---- |
| 车辆资产 | 设备绑定车辆，外键为车辆 VIN 码；基数为车辆 1 : N 设备 | 台账与详情页的车辆 VIN 码提供跳转车辆资产详情的入口 |
| SIM 卡管理 | 设备与 SIM 卡为当前 1 : 1 绑定，外键为 IMSI | 台账与详情页的 IMSI 提供跳转 SIM 卡详情的入口；SIM 卡台账为设备绑定提供可选卡源 |
| 车辆建档 | 设备字段与车辆档案「硬件信息」表对齐 | 车辆档案中的终端信息以设备台账为准，避免同一信息多处维护 |
| 项目 | 设备本身不存放项目字段，经绑定车辆间接归属项目 | 按「项目」分组时，未绑定车辆或车辆无归属项目的设备归入「无分组」 |
| 流量费用明细 | 经设备与 SIM 卡的绑定关系间接关联 | 设备换绑会改变 SIM 卡与车辆的对应关系，影响按车辆归集的流量费用口径 |
