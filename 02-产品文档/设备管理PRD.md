## 名词解释

| 名词/缩写 | 解释 |
| ---------- | ---- |
| 设备 | 安装在车辆上的车端网联终端，包含 T-Box、ADU、OBU、DTU、视频盒子五类 |
| 设备识别码 | 设备的全局唯一业务标识，是设备台账与绑定关系的锚点 |
| 绑定关系 | 设备与车辆、设备与 SIM 卡之间的当前关联关系，支持解绑并保留历史 |
| 车架号 | 车辆识别代号，车辆唯一标识。设备自身不含车架号字段，车架号经绑定车辆取得 |
| IMSI | 国际移动用户识别码，SIM 卡唯一标识 |

## 1. 业务背景与使用角色

### 1.1 业务背景
- 模块定位：设备管理是车端网联终端的主数据台账，独立维护设备自身信息，并承载设备与车辆、SIM 卡的当前绑定关系。
- 核心特点：设备是独立于车辆的业务对象，与车辆为「一车多终端」关系；绑定关系随时点变化并全程留痕，换绑不重建设备台账。
- 关联模块关系：设备绑定车辆后经车架号关联车辆资产与归属项目；设备绑定 SIM 卡后经 IMSI 关联 SIM 卡台账与流量费用；设备字段与车辆档案「硬件信息」表对齐。
- 业务痛点：终端信息原先随车辆档案维护，无法统一管理备件终端、换绑与一车多终端场景，终端与车辆、SIM 卡的对应关系缺少可追溯的台账。

### 1.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 管理员 | 维护设备主数据、维护设备与车辆和 SIM 卡的绑定关系、查询与导出设备台账、查看设备详情、删除设备 | WEB |
| 项目经理 | 查询与导出设备台账、查看设备详情 | WEB |

本期为静态高保真原型，使用 mock 数据，不实现按项目的数据权限控制与真实文件导出；登录后统一具备上述表格中角色的操作能力。

### 1.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 终端可查 | 设备信息集中登记，支持按设备类型页签、车辆与项目筛选快速定位单个终端 |
| 关系可溯 | 设备与车辆、SIM 卡的绑定与解绑全部留痕，可回溯历史变更 |
| 口径统一 | 设备字段与车辆档案「硬件信息」表对齐，避免同一份信息多处维护造成差异 |

## 3. 功能详细设计

### 3.1 F01 设备台账浏览与检索

#### 3.1.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 从设备类型页签与查询条件两个方向快速定位目标设备，查看其台账信息并导出 |
| 使用角色 | 管理员、项目经理 |
| 触发条件 | 进入「车辆管理 / 设备管理」菜单，或需要按设备类型、车辆、项目核对终端 |
| 功能边界 | 包含设备类型页签浏览、识别码与车架号检索、条件筛选、分页、导出与行内操作入口；不包含设备新增编辑与绑定关系维护本身 |
| 成功结果 | 定位到目标设备或设备集合，并可导出当前结果 |

#### 3.1.3 数据与字段规则

**输入与查询条件：**

| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | -------------------- | ------ | ------------- |
| 设备类型页签 | 顶部页签，浏览维度 | 单选切换，固定展示全部与五类设备 | 全部 | 枚举值：全部、T-Box、ADU、OBU、DTU、视频盒子；页签台数按当前已应用的查询条件统计，0 台页签仍可点击并展示空态 |
| 设备识别码 | 查询条件（外露） | 手工输入 | 空 | 对设备识别码模糊匹配，不区分大小写 |
| 车架号 | 查询条件（外露） | 手工输入 | 空 | 对绑定车辆的车架号模糊匹配，不区分大小写；未绑定车辆的设备不命中 |
| 状态 | 查询条件（外露） | 下拉单选 | 全部 | 枚举值：正常、维修中、已报废 |
| 归属项目 | 查询条件（收在「展开」内） | 下拉单选，来源为车辆归属项目 | 全部 | 经绑定车辆间接取值；未绑定车辆或车辆无归属项目的设备在选择具体项目时不命中 |
| 是否有SIM卡 | 查询条件（收在「展开」内） | 下拉单选 | 全部 | 枚举值：有、无 |
| 是否绑定车辆 | 查询条件（收在「展开」内） | 下拉单选，来源为设备当前绑定关系 | 全部 | 枚举值：已绑定（当前绑定车架号非空）、未绑定（当前绑定车架号为空） |

**展示与输出字段：**

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 设备名称 | 设备台账名称 | 设备主数据 | — | 显示「—」 |
| 设备类型 | 设备分类 | 设备主数据 | 枚举值：T-Box、ADU、OBU、DTU、视频盒子 | — |
| 设备识别码 | 设备唯一标识 | 设备主数据 | — | — |
| 车架号 | 当前绑定车辆的车架号 | 绑定关系 | 提供跳转车辆资产详情入口 | 显示「未绑定车辆」 |
| 是否有SIM卡 | 当前是否绑定 SIM 卡 | 绑定关系 | 由 IMSI 是否为空判定 | 显示「无」 |
| IMSI | 当前绑定的 SIM 卡标识 | 绑定关系 | 提供跳转 SIM 卡详情入口 | 显示「未绑定」 |
| 厂商 / 型号 | 设备厂商与型号 | 设备主数据 | 两项拼接展示 | 显示「—」 |

#### 3.1.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R01 | 页面加载 | 顶部默认选中「全部」页签，查询条件初始为空，表格展示全部设备 | 表格按设备识别码升序展示第一页 |
| R02 | 切换设备类型页签 | 表格收敛为该类型设备，查询条件保持不变 | 分页重置到第 1 页，已勾选清空 |
| R03 | 点击「查询」 | 查询结果 = 当前页签 ∩ 六项查询条件（设备识别码、车架号、状态、归属项目、是否有SIM卡、是否绑定车辆）；识别码与车架号同时填写时取交集（均模糊匹配、不区分大小写） | 分页重置到第 1 页，已勾选清空；页签台数与总数同步刷新 |
| R04 | 点击「重置」 | 清空六项查询条件并收起「展开」内的条件，保持当前页签 | 分页重置到第 1 页，已勾选清空；页签台数恢复为该类型的全部设备数 |
| R05 | 页签台数为 0 | 该页签仍可点击 | 表格展示空态 |
| R06 | 查询条件已填写但未点击「查询」 | 未应用的输入不改变表格结果与页签台数 | 表格与页签台数保持上一次查询结果 |
| R07 | 页签台数口径 | 各类型页签台数按当前已应用的查询条件统计，「全部」页签为查询条件下的设备总数 | 点击「查询」或「重置」后立即刷新 |
| R08 | 排序规则 | 表格统一按设备识别码升序排列 | — |

#### 3.1.5 交互流程

1. 用户进入设备管理页，系统加载设备台账并默认选中「全部」页签，表格展示全部设备的第一页，页签台数按当前查询条件（初始为空）统计。
2. 用户切换设备类型页签（全部、T-Box、ADU、OBU、DTU、视频盒子），表格收敛为该类型设备，分页回到第 1 页并清空勾选，查询条件保持不变。
3. 用户在查询区输入设备识别码、车架号或选择状态后点击「查询」或回车，表格按「当前页签 ∩ 查询条件」展示结果；点击「展开」可展开归属项目、是否有SIM卡、是否绑定车辆三项条件，六项同时填写时取交集。
4. 用户点击「重置」，清空六项查询条件并收起「展开」内的条件，保持当前页签，表格回到该页签下的全部设备。
5. 页签台数随查询结果同步刷新；台数为 0 的页签仍可点击，点击后表格展示空态。
6. 用户翻页或调整每页条数，表格展示对应数据。
7. 用户点击「导出」处理结果：
   - 已有勾选 → 导出勾选的设备
   - 无勾选 → 导出当前页签与查询条件下的全部设备
   - 当前无数据 → 提示无内容可导出，不生成文件

#### 3.1.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 查询无匹配设备 | 当前页签与查询条件取交集后为空 | 表格展示空态，对应页签台数显示为 0 | 提示暂无匹配设备，引导调整查询条件或切换设备类型 | 点击「重置」或修改查询条件 |
| 导出无内容 | 当前无数据 | 不生成导出文件 | 提示当前没有可导出的设备 | 调整条件后重试 |

### 3.2 F02 设备主数据维护

#### 3.2.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 建立与更新设备主数据，保证设备识别码唯一 |
| 使用角色 | 管理员 |
| 触发条件 | 新终端入库需要登记，或设备信息发生变化需要更正 |
| 功能边界 | 仅维护设备自身字段；设备与车辆、SIM 卡的关系在绑定关系维护中处理 |
| 成功结果 | 设备写入台账并刷新列表；新增后自动定位到该设备 |

#### 3.2.3 数据与字段规则

| 字段 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| ---- | -------- | -------------------- | ------ | ------------- |
| 设备名称 | 设备台账名称 | 手工输入 | 空 | 必填 |
| 设备类型 | 设备分类 | 下拉单选 | 空 | 必填；枚举值：T-Box、ADU、OBU、DTU、视频盒子 |

### 3.3 F03 绑定关系维护

#### 3.3.1 功能目标与范围

2. 用户通过可搜索选择器选择绑定车辆与绑定 SIM 卡（支持模糊匹配与命中高亮），可清空任一项以解绑，随后点击保存。

3. 处理结果：
   - 成功 → 更新当前绑定关系 + 按变化的绑定项写入变更日志 + 刷新台账列表与页签台数 + 提示绑定关系已保存
   - 无变化 → 提示「绑定关系无变化，未生成变更记录」，不写入日志、不更新最近维护时间
   - 失败 → 提示该 SIM 卡已绑定其他设备及其识别码 + 弹窗与已选内容保留 + 用户可重新选择后保存

#### 3.4.2 设备变更日志

详情页「当前绑定」下方展示该设备的变更日志，为只读的字段级事件表，列与对齐口径对齐《车辆资产管理 PRD》详情页的「变更日志」Tab。

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 操作类型 | 本次变更的行为 | 系统写入 | 枚举值：新增、修改；新增用绿色标签，修改用蓝色标签 | — |

## 4. 业务规则汇总

### 4.1 唯一性规则
- 设备识别码全局唯一，新增与编辑时均校验，不区分大小写。
- 同一张 SIM 卡在同一时间只能绑定一个设备，绑定保存时校验。
- 设备与车辆为「一车多终端」关系，同一车辆可绑定多台设备，不设唯一性约束。

### 4.3 状态流转
设备状态枚举值：正常、维修中、已报废。状态由人工在设备表单中直接维护，不限制状态之间的互转，也不驱动车辆状态或其他模块数据的变化。

### 4.4 字段联动规则

| 触发字段 | 触发条件 | 联动行为 |
| -------- | -------- | -------- |
| 绑定车辆 | 变更设备绑定的车辆 | 「车架号」列同步刷新；按归属项目查询时结果随之变化 |
| 绑定 SIM 卡 | 变更设备绑定的 SIM 卡 | 「是否有SIM卡」与「IMSI」两列同步反映最新绑定 |
| 设备类型 | 新增或编辑时变更 | 设备归属的设备类型页签随之变化，页签台数同步刷新 |

### 4.6 校验规则

| 场景 | 校验项 | 处理 |
| ---- | ------ | ---- |
| 保存设备 | 设备名称、设备类型、设备识别码必填 | 阻断保存并提示缺失项 |
| 保存设备 | 设备识别码全局唯一 | 阻断保存并提示识别码已存在 |
| 保存绑定 | SIM 卡当前未被其他设备占用 | 阻断保存并提示占用设备识别码 |
| 删除设备 | 设备当前未绑定车辆且未绑定 SIM 卡 | 阻断删除并提示占用对象（车牌与车架号、IMSI） |

### 4.9 变更日志记录规则
设备主数据与绑定关系的变更统一写入**设备变更日志**，按字段级事件记录，一条记录包含操作类型、修改字段、修改前、修改后、操作人与操作时间，按操作时间倒序展示，写入后不可修改。

| 变更场景 | 记录口径 |
| -------- | -------- |
| 新增设备 | 记录一条「新增」事件，修改字段与修改前后值显示「—」 |
| 编辑设备 | 按变化字段逐项记录，修改前/后为该字段的原值与新值；未变化的字段不记 |
| 绑定车辆 | 记录「车架号」一条，修改前为原车架号，无则显示「—」 |
| 解绑车辆 | 记录「车架号」一条，修改后显示「—」 |
| 绑定 / 更换 / 解绑 SIM 卡 | 记录「IMSI」一条，修改前/后为对应 IMSI，空值显示「—」 |
| 保存后无任何字段变化 | 不写入日志，不更新最近维护时间 |
| 删除设备 | 不写入日志（见 F06）：设备移除后其变更日志一并移除；如需保留解绑痕迹，应在删除前先解除绑定，解绑会写入「车架号」「IMSI」记录 |

不记录设备删除：删除不写入设备变更日志，也不更新最近维护时间，被删设备的历史日志随设备一并移除，删除操作不可恢复。变更日志仅设备管理模块内部使用，不写入车辆资产详情的变更日志（车辆侧变更日志仅记录车辆自身字段）。

## 5. 关联模块说明

| 关联模块 | 关联关系 | 说明 |
| -------- | -------- | ---- |
| 车辆资产 | 设备绑定车辆，外键为车辆车架号；基数为车辆 1 : N 设备 | 台账与详情页的车架号提供跳转车辆资产详情的入口 |
| SIM 卡管理 | 设备与 SIM 卡为当前 1 : 1 绑定，外键为 IMSI | 台账与详情页的 IMSI 提供跳转 SIM 卡详情的入口；SIM 卡台账为设备绑定提供可选卡源 |
| 车辆建档 | 设备字段与车辆档案「硬件信息」表对齐 | 车辆档案中的终端信息以设备台账为准，避免同一信息多处维护 |
| 项目 | 设备本身不存放项目字段，经绑定车辆间接归属项目 | 台账页提供「归属项目」查询条件；未绑定车辆或车辆无归属项目的设备在选择具体项目时不命中 |
| 流量费用明细 | 经设备与 SIM 卡的绑定关系间接关联 | 设备换绑会改变 SIM 卡与车辆的对应关系，影响按车辆归集的流量费用口径 |
