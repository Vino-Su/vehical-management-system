## 1. 背景与目标

车辆实时监管用于查看车辆网联终端上报的运行、故障和异常数据，支持运营人员按车辆、项目和时间快速定位数据，并将查询结果或选中记录导出用于复盘。

本文档对应 `01-需求文档/车辆实时监管.md` 第 2.2、2.3、2.4 节。原“车辆异常告警”统一命名为“车辆异常记录”。

## 2. 功能范围

### 2.0 车辆监管一张图

#### 2.0.1 地图与点位

| 类别 | 要求 |
| --- | --- |
| 底图 | 使用 Leaflet 1.9.4，本地加载 JS/CSS；地图瓦片使用 OpenStreetMap，保留版权标识 |
| 坐标 | 终端位置按 WGS84 坐标展示；高保真阶段忽略无效、缺失或过期坐标 |
| 聚合 | 默认按市聚合；市级聚合点显示车辆总数。点击聚合点后地图缩放至车辆级别并展示该市车辆点位；缩放层级低于车辆级别时恢复市级聚合 |
| 车辆图标 | 按车型使用图标；车辆标识按车牌号、网联编号、车架号优先级显示。远程驾驶为绿色，自动驾驶为蓝色，人工驾驶为灰色 |
| 异常角标 | 显示当日故障数与异常事件数之和；数量大于 0 时显示角标并叠加闪烁效果 |
| 底部图例 | 展示远程驾驶、自动驾驶、人工驾驶三种颜色图例 |

#### 2.0.2 搜索、筛选与联动

- 地图右上角默认仅展示搜索、筛选两个图标按钮；点击后分别展开搜索框和筛选浮层，同一时间仅展开一个面板，点击地图空白处或按 `Esc` 关闭。
- 搜索框支持车架号、车牌号、网联编号精确搜索，搜索结果聚焦并选中车辆。
- 筛选浮层中的项目、区域、车型均使用可多选下拉框；不同筛选项之间按 AND 组合，同一筛选项内部按 OR 组合；选项来自全量主数据。
- “仅显示故障与异常车辆”按照当日故障数或异常事件数大于 0 判断，并与“异常车辆”统计筛选保持同步。
- 车辆总数、异常车辆、在线车辆均可点击筛选：三项互斥，默认选择车辆总数；车辆总数恢复当前查询范围内全部车辆，异常车辆仅展示当日故障数或异常事件数大于 0 的车辆，在线车辆仅展示平台连接状态为在线的车辆，在线状态未上报不计入在线数。三个统计数均以项目、区域、车型及精确搜索组成的基础查询范围计算，不受当前统计类别影响。
- 切换统计类别时保留项目、区域、车型与搜索条件，同步更新车辆列表、地图及异常与故障列表；有结果时地图调整至结果范围，无结果时列表显示空态并清除地图车辆点位；当前选中车辆不在结果内时取消其选中状态。清空筛选时恢复车辆总数类别。
- 数据面板固定在地图左侧，支持收起；车辆列表和异常与故障两个 Tab 均不设置独立查询条件组，仅保留按项目、车型、区域切换的分组维度，默认按项目分组并打开车辆列表 Tab。
- 车辆列表卡片仅展示车牌号、网联编号和车架号：车牌号与网联编号按“车牌号-网联编号”组合，车架号单独展示；缺省字段直接省略，连接符仅在车牌号与网联编号均有值时显示。
- 监管一张图的车辆卡片仅根据已有运行状态和补给状态展示对应状态图标，悬停可查看状态名称；状态枚举沿用第 2.1.3 节，缺省或未知值不展示对应状态图标。卡片不显示驾驶状态与在线状态，驾驶状态沿用地图展示；轨迹、视频图标保留原操作。
- 监管一张图与运行数据页的卡片采用一致的选中提示，左侧蓝色标识条仅表示当前选中车辆。
- 地图右上角的搜索和筛选结果同步作用于地图、车辆列表、异常与故障列表；切换分组维度不改变当前搜索及筛选条件。列表选车或选择异常/故障卡片后，地图聚焦并选中对应车辆；地图选车后车辆列表同步高亮。

#### 2.0.3 车辆信息弹窗

- 标题按“车牌号/网联编号/车架号 - 车型 - 所属项目”展示。
- “实时数据”Tab 展示驾驶状态、信号强度、运行状态、补给状态、车辆速度、档位、SOC、剩余水量、垃圾箱状态和数据采集时间。SOC、剩余水量、垃圾箱状态均显示百分比。
- “故障与异常”Tab 以记录卡片展示，按上报时间倒序排列，支持查看更多。
- 轨迹回放不打开全屏或独立地图弹窗，直接在车辆监管一张图的原地图窗口内绘制；页面顶部导航、左侧导航和车辆数据面板保持可见。进入回放时隐藏原地图的统计、搜索筛选、普通图例及车辆聚合点，显示轨迹图例、地图工具和底部回放控制台；关闭后恢复进入回放前的地图视角和普通车辆点位。
- 回放控制台默认查询当天轨迹，支持选择日期、开始时间、结束时间和车辆；结束时间必须晚于开始时间。查询后在地图绘制起点、终点、完整轨迹、已播放轨迹和当前车辆位置。
- 回放支持播放/暂停、0.5×/1×/2×/4×倍速和拖动时间轴；播放或拖动时同步更新当前时间、车辆速度、驾驶状态和地图车辆位置，并提供视频回看入口。
- 视频在当前地图页面内打开播放弹窗，按车辆档案中的摄像头信息展示多摄像头画面。

#### 2.0.4 高保真阶段边界

- 高保真阶段不实现实时推送、刷新频率、数据过期判定、接口失败重试和权限审计，使用本地模拟数据完成交互验证。
- 轨迹播放和视频播放使用可交互模拟内容，后续接入真实接口和播放协议。

### 2.1 车辆运行数据

#### 2.1.1 页面结构

页面采用左右分栏。左侧展示可查询、分组和选中的车辆列表，右侧展示当前车辆的运行数据明细。

右侧顶部不展示选中车辆的信息摘要（车牌主标识、在线状态标签、车架号、所属项目与车型），数据采集时间查询区与明细列表直接作为右栏首行；当前选中车辆仅由左侧列表的选中态标识。

#### 2.1.2 车辆列表

| 类别 | 要求 |
| --- | --- |
| 查询条件 | 车架号、车牌号、车型名称、项目；默认仅显示车架号，车牌号、车型名称和项目通过“展开更多/收起”切换显示 |
| 卡片内容 | 仅展示车牌号、网联编号和车架号，标识组合及缺省处理同第 2.0.2 节车辆列表卡片；不展示车型信息 |
| 分组方式 | 支持按项目或车型名称切换，默认按项目分组 |
| 无归属数据 | 当前分组字段为空时统一进入“无分组” |
| 分组交互 | 显示组内车辆数量，支持展开和收起；初始化、查询重置和切换分组方式时，当前选中车辆所在分组置于首位并仅展开该首个分组，其余分组收起 |
| 默认选择 | 选中当前查询结果中车架号排序最前的车辆 |
| 联动 | 选中其他车辆后，右侧切换为该车辆的运行明细 |

#### 2.1.3 运行数据明细

查询条件为数据采集时间范围。开始时间晚于结束时间时不执行查询，并给出错误提示。

| 序号 | 字段 |
| ---: | --- |
| 1 | 车架号 |
| 2 | 所属项目 |
| 3 | 经度 |
| 4 | 纬度 |
| 5 | 驾驶状态 |
| 6 | 信号强度 |
| 7 | 运行状态 |
| 8 | 补给状态 |
| 9 | 车辆速度(km/h) |
| 10 | 档位 |
| 11 | 物联网终端在线状态 |
| 12 | SOC(%) |
| 13 | 剩余水量(%) |
| 14 | 垃圾箱状态(%) |
| 15 | 数据采集时间 |

驾驶状态的枚举值为：自动驾驶、远程驾驶、人工驾驶；运行状态的枚举值为：作业、转场、运维、停靠、关机；补给状态的枚举值为：未补给、充电、加水、换电。
车辆运行数据明细中的驾驶状态、运行状态、补给状态均以标签展示；车辆速度单位km/h标注在列表和导出表头，数据单元格仅显示数值。
SOC、剩余水量、垃圾箱状态均按百分比展示，有效范围为0%～100%，0%为有效值；缺失、无效或不适用时显示“—”，不得补为0%。信号强度按来源定义展示，不自行换算单位或制定等级阈值。驾驶状态中的远程驾驶以本次确认口径为准，不从AUTO/MANUAL自行推导。

档位保留；物联网终端在线状态由平台连接状态提供，与信号强度、关机状态分开。列表、导出及单车监控使用一致字段和单位；导出范围规则沿用原设计。删除接管状态、横纵向加速度、侧倾及横摆角速度，原混合“车辆作业模式”由运行状态与补给状态替代。车辆档案、项目、费用及独立业务记录不受此删除范围影响。

### 2.2 车辆故障信息

车辆故障信息作为故障上报台账，记录车辆主动上报的故障代码及整车、上装原始故障等级。本期范围为记录、查询、分页和导出，不包含故障详情、发生过程归并、恢复判定、人工处置及维修闭环。

| 类别 | 内容 |
| --- | --- |
| 查询条件 | 车架号、车牌号、网联编号、车型、故障系统、所属项目、故障码、故障上报时间范围 |
| 列表及导出字段 | 车架号、车牌号、网联编号、所属项目、车型、故障系统、故障码、故障定义、整车故障等级、上装故障等级、故障上报时间、平台接收时间 |
| 车型范围 | 独角兽、麒麟-扫车、麒麟-洒水车、浩克-扫车、浩克-洒水车、麒麟-R3S；按上报车辆档案关联 |
| 故障系统 | 整车、驱动系统、电池系统、制动系统、转向系统、上装系统、扫盘系统、滚扫电机、风机电机；依据上报字段确定，不根据故障码前缀推断 |

#### 2.2.1 上报字段与车型范围
| 上报参数 | 参考表中标记支持的车型 |
| --- | --- |
| 整车、驱动系统、电池系统、上装系统故障代码；整车和上装故障等级 | 全部6款车型 |
| 制动系统、转向系统故障代码 | 独角兽、麒麟-扫车、麒麟-洒水车、麒麟-R3S |
| 扫盘系统、风机电机故障代码 | 独角兽、麒麟-扫车、浩克-扫车、麒麟-R3S |
| 滚扫电机故障代码 | 独角兽 |

参考依据为《酷哇自研车型参数对照表》。未标记支持的参数不能补为“无故障”；实际接入能力以车辆上报协议为准，列表只记录收到的信息，不生成未上报系统的正常记录。
#### 2.2.2 记录与字段规则
1. 同一车辆、同一故障码多次上报分别保留，不合并为一次故障，不计算故障持续时间。多码上报按系统、故障码展开为明细，保留各自所属系统；同一报文中的整车、上装原始等级及时间随明细保留。记录条数为上报明细条数，不等同于独立故障次数。
2. 故障码原样保留，故障定义仅展示报文或已确认映射提供的内容；没有定义时显示“—”，不得自动生成诊断或维修建议。仅提供故障等级的故障上报仍可记录，故障码及定义显示“—”。
3. 整车故障等级按原值记录，参考表给出的范围为0/1/2/3；上装故障等级按上报原值记录，参考表未定义其枚举含义。本期不将等级转换为严重、一般、提示，不将整车或上装等级认定为单条故障码的等级。
4. 缺失字段显示“—”，0为有效原值；同一明细可同时保留整车等级、上装等级，两者均为本次上报的独立字段。
5. 故障上报时间记录车辆侧上报时间，平台接收时间记录平台实际接收时间，分别展示至秒；不得用接收时间补齐缺失的上报时间。默认按上报时间倒序，缺失上报时间的记录排在最后，同上报时间按接收时间倒序。
6. 上报时间查询包含起止边界，支持秒；起始时间晚于结束时间时提示原因并保留原查询结果。限定上报时间范围时，不纳入上报时间缺失的记录。
7. 接收单车运行监控传入的车架号、车牌号和网联编号，带入查询；组合条件按同时满足查询。查询及重置回到第一页并清空选择，空结果保留筛选条件并展示空状态。
8. 台账沿用公共导出组件的当前页选中导出规则；跨页勾选可以保留，选中导出只导出当前页勾选的记录，当前页没有勾选时提示用户。无勾选时经确认导出全部查询结果；列表与导出的字段、顺序、缺失值及0值保持一致。
9. 故障与策略异常继续分别记录。台账记录不直接修改车辆业务状态，不直接写入生命周期，不增加确认、关闭或工单操作。

查询区不使用独立外框，表格上方不展示额外说明文字。操作行仅保留「导出」次按钮，靠左排列（不将「导出」右对齐），按钮不带图标；不展示「已选 N 条」提示文案，已选数量在导出结果提示中体现。

### 2.3 车辆异常记录

车辆异常记录用于展示车辆触发预先设定的策略规则后生成的异常事件。

| 类别 | 内容 |
| --- | --- |
| 查询条件 | 车架号、车牌号、网联编号、所属项目、异常类型、异常上报时间范围 |
| 异常类型 | 超时停靠、超速行驶、限行区行驶 |
| 列表字段 | 车架号、车牌号、网联编号、所属项目、异常类型、开始时间、结束时间、持续时长（min）、异常上报时间 |

操作行仅保留「导出」次按钮，靠左排列（不将「导出」右对齐），按钮不带图标；不展示「已选 N 条」提示文案与「清空选择」入口，已选数量在导出结果提示中体现。

## 3. 公共交互规则

1. 查询后列表总数、当前页和分页状态同步更新，并清空原有勾选。
2. 重置清空当前页面的查询条件、勾选和页码，恢复全部数据。
3. 列表默认每页 10 条，支持切换每页条数；显示总记录数和当前页码。
4. 全选仅对当前页生效，单条勾选在切换页码后保留；车辆故障信息页与车辆异常记录页不展示已选数量提示，勾选统计仅在导出结果提示中体现。
5. 当存在勾选数据时，点击“导出”仅导出选中记录。
6. 未勾选数据时，点击“导出”须二次确认，确认后导出当前查询条件下的全部记录。
7. 查询无结果时显示空状态；无可导出数据时不生成空文件并给出提示。
8. 导出字段、字段顺序与当前页面列表字段保持一致，不包含复选框列。

## 5. 验收标准

- 第一阶段验收：地图弹窗、车辆运行数据及导出均遵循第2.1.3节的字段规则；图例、车辆标识和轨迹回放统一使用驾驶状态及三种枚举；缺失百分比显示“—”，0值显示0%；原查询、分页、选择及导出范围保持有效。

1. 四个页面可从页面索引和公共侧边导航进入，导航高亮与当前页一致。
2. 查询、重置、分页、每页条数、单选和当前页全选均可交互。
3. 车辆运行数据页的左侧查询区默认仅显示车架号，可展开或收起其余条件；页面默认按项目分组并选中车架号最小的车辆，仅展开首个分组；切换车辆时右侧数据联动更新。
4. 车辆异常记录页不再显示“车辆异常告警”旧名称。
5. 已勾选导出与未勾选导出的范围、确认流程和字段均符合第 3 节规则。
