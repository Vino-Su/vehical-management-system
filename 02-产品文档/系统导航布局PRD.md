## 2. 背景与目标

原布局将全部业务模块平铺在单一侧栏中。当业务模块增加到三级时，导航层级不清晰，且占用较多纵向空间。

本次调整将一级模块放至顶部，侧栏仅呈现当前一级模块的二级和三级菜单。页面业务内容、既有 URL 和已实现功能保持不变。

## 3. 信息架构

### 3.1 顶部一级模块

顶部展示以下一级模块，并以蓝色实底突出当前模块：车辆管理、运行监管、维保管理、合规与风险、费用管理、退出管理、数据分析、系统管理。

一级模块与 `01-需求文档/页面框架.md` 保持一致。其中“资产管理”和“SIM 卡管理”属于车辆管理；“车辆调度”和“车辆运营”属于运行监管。运行监管侧栏顺序为车辆调度、实时监管、异常事件、车辆运营；车辆运营下的“用车记录”为可访问的三级页面，深链进入时应自动高亮。

### 3.2 侧栏二三级菜单

1. 切换顶部一级模块时，侧栏同步替换为该模块下的二级菜单与三级功能；系统默认进入并选中该模块首个可访问的三级页面。若模块内页面均未开放，则保留菜单切换并提示暂无可访问页面。
2. 二级菜单可独立展开或收起；当前页面所属菜单默认展开。
3. 三级功能为可访问的具体业务页。已实现功能保留原有页面地址；未实现功能展示“未开放”状态且不可跳转。
4. 通过 URL 直接进入已实现页面时，系统自动选中对应的顶部模块、二级菜单与三级菜单。

## 4. 布局与交互

1. 顶部导航高度为 64px，包含系统标识、一级模块、项目选择与用户信息。品牌区宽度与默认侧栏一致（224px），一级模块从侧栏右边界开始排列；一级模块标题前不展示图标占位。
2. 侧栏默认宽度为 224px，支持收起至 64px；收起状态以浏览器本地存储记忆。
3. 侧栏收起后保留二级模块标识与展开按钮，内容区自动扩展。
4. 含固定底部操作栏的编辑页面，在侧栏收起时同步调整左侧偏移，避免遮挡内容。
5. 1366px 宽度下，顶部模块支持横向滚动，保障模块名称不被截断。

### 4.1 用户名称与退出登录入口
各业务页面统一显示当前用户名称，用户可通过名称入口打开账号菜单；本期退出登录仅提供占位入口。
| 项目 | 业务规则 |
| --- | --- |
| 用户名称 | 优先显示当前用户名称，静态预览未提供名称时沿用“管理员”；超长名称可查看完整内容。 |
| 账号菜单 | 点击用户名称展开菜单，再次点击、点击菜单外区域或按 Esc 收起菜单；支持键盘操作。 |
| 退出登录 | 菜单提供“退出登录”占位按钮，点击后提示“退出登录功能暂未开放”，保留当前页面与数据。 |
| 本期范围 | 不新增登录页面，不执行真实退出登录或账号状态变更；不展示通知占位入口。 |

交互流程：
1. 用户进入任一业务页面，查看当前用户名称。
2. 点击名称，系统展示账号菜单及“退出登录”入口。
3. 点击“退出登录”，菜单收起并提示暂未开放；用户继续使用当前页面。

## 5. 验收标准

1. 所有已实现页面均使用同一套顶部一级导航和二三级侧栏。
2. 车辆建档、车辆资产、标签、车型四类页面位于“车辆管理”；可用车辆库和调度记录位于“运行监管 > 车辆调度”；用车记录位于“运行监管 > 车辆运营”。
3. 侧栏展开、收起、一级模块切换与深链定位均可用，且不产生 JavaScript 报错；切换一级模块后默认进入并选中该模块首个可访问页面。
4. 1366×768 与 1920×1080 下内容区、表格和固定底部操作栏无重叠或溢出。
5. 所有业务页均显示用户名称与账号菜单；超长名称不挤压导航，退出占位按钮提供明确提示且不触发页面跳转。
