## 名词解释

| 名词/缩写 | 解释 |
| ---------- | ---- |
| 流量池 | 公司统一采购的同档位套餐 SIM 卡组成的共享流量资源池；流量池内的 SIM 卡共享单位流量成本 |
| 单位成本 | 元/GB；流量池当月充值费用总额 ÷ 流量池实际使用总量 |
| 实际流量费用 | 月度结束后按「当月实际使用流量 × 单位成本」计算的正式流量费用，本文档中简称流量费用 |
| 流量使用率 | 车辆当月实际使用流量 ÷ 该车关联 SIM 卡套餐额度合计 |
| VIN 码 | 车辆识别代号，车辆唯一标识 |
| IMSI | 国际移动用户识别码，SIM 卡唯一标识 |

## 1. 业务背景与使用角色

### 1.1 业务背景
- 模块定位：费用管理 > 流量费用下的核算结果查询页面，用于按车辆、按月度查看流量费用，支撑流量成本的月度归集与对账。
- 核心特点：以车辆为主体、以自然月为统计粒度；费用由系统按「实际用量 × 单位成本」核算生成，页面数据只读，不提供人工新增、编辑与删除。
- 关联模块关系：车辆档案提供车辆标识与归属项目；SIM 卡管理提供 SIM 卡与车辆的绑定关系、套餐额度与日/月用量；流量池充值费用与单位成本由后续接入的核算数据提供。
- 业务痛点：SIM 卡采用公司统一采购与企业共享流量池模式，单卡、单车的实际流量消耗与成本不清晰；流量池利用率偏低；缺少「卡—量—价—车—项目」的完整费用链路。
### 1.2 使用角色

| 角色 | 该模块中的职责 | 客户端 |
| ---- | ------------ | ------ |
| 财务人员 | 按月查看与核对车辆流量费用，导出明细用于成本归集与对账 | WEB |
| 费用管理员 | 查看车辆月度流量费用明细，核对用量、单位成本与费用构成 | WEB |
| 项目经理 | 查看权限范围内项目的车辆流量费用 | WEB |
| 管理层 | 查看全局车辆流量成本 | WEB |

### 1.3 核心目标与价值

| 目标维度 | 说明 |
| -------- | ---- |
| 成本透明 | 每辆车每月的流量费用、用量、使用率与单位成本可查、可算、可追溯 |
| 成本归集 | 打通「流量池 → SIM 卡 → 车辆 → 项目」的费用归集链路，支撑月度结算 |
| 对账支撑 | 提供车辆月度流量费用明细导出，支撑与流量池充值费用的对账核对 |

## 3. 功能详细设计

### 3.1 F01 月度流量费用查询

#### 3.1.1 功能目标与范围

| 项目 | 说明 |
| ---- | ---- |
| 功能目标 | 按月度查询并核对每辆车的流量费用及其构成要素 |
| 使用角色 | 财务人员、费用管理员、项目经理、管理层 |
| 触发条件 | 用户进入「费用管理 > 流量费用 > 流量费用明细」页面 |
| 功能边界 | 包含：条件查询、重置、月度汇总列表、合计统计、分页、勾选。不包含：费用数据的人工新增、编辑与删除，核算状态管理，充值费用导入 |
| 成功结果 | 列表按统计月份展示符合查询条件的每车每月流量费用，并展示条数、车辆数、用量合计与费用合计 |

#### 3.1.2 使用条件与权限

| 角色 | 可执行操作 | 数据范围 | 前置条件 |
| ---- | ---------- | -------- | -------- |
| 财务人员、费用管理员、管理层 | 查询、查看、导出 | 全部项目 | 无 |
| 项目经理 | 查询、查看、导出 | 归属项目在其负责范围内的车辆 | 无 |

#### 3.1.3 数据与字段规则

**输入与查询条件：**

| 字段/条件 | 业务含义 | 取值方式或数据来源 | 默认值 | 校验/匹配规则 |
| --------- | -------- | -------------------- | ------ | ------------- |
| 统计月份 | 费用归属的自然月，按起止月份区间查询 | 月份选择 | 近 12 个月（含当月） | 起始月份不得晚于结束月份；超出范围的记录不展示 |
| 车牌号 | 车辆牌照号码 | 手工输入 | 空 | 模糊匹配 |
| VIN 码 | 车辆识别代号 | 手工输入 | 空 | 模糊匹配 |
| 归属项目 | 车辆所属项目 | 下拉选择（项目主数据） | 空（全部项目） | 精确匹配 |

**展示与输出字段：**

| 字段 | 业务含义 | 数据来源 | 格式/口径规则 | 空值处理 |
| ---- | -------- | -------- | ------------- | -------- |
| 统计月份 | 费用归属月 | 核算结果 | 格式 yyyy-MM | — |
| 车牌号 | 车辆牌照号码 | 车辆档案 | — | 未绑定车牌时显示「—」 |
| VIN 码 | 车辆识别代号 | 车辆档案 | — | — |
| 归属项目 | 车辆所属项目 | 车辆档案 | — | 无归属时显示「未归属」 |
| 关联卡数 | 该车当月归属的 SIM 卡数量 | SIM 卡绑定关系 | 整数 | 无绑定卡时显示 0 |
| 当月用量(GB) | 该车当月全部 SIM 卡实际使用流量之和 | SIM 卡用量数据 | 保留 2 位小数 | 无用量时显示 0.00 |
| 流量使用率 | 当月用量 ÷ 该车关联 SIM 卡套餐额度合计 | 计算得出 | 百分比，保留 1 位小数；超过 100% 标识为超额度 | 额度合计为 0 时显示「—」 |
| 单位成本(元/GB) | 该车当月加权平均单位成本 = 流量费用 ÷ 当月用量 | 计算得出 | 保留 2 位小数 | 当月用量为 0 时显示「—」 |
| 流量费用(元) | 该车当月流量费用合计 | 计算得出 | 保留 2 位小数 | 无费用时显示 0.00 |
| 操作 | 费用明细详情入口 | — | — | — |

**列表与合计规则：** 列表默认按统计月份倒序、同月按 VIN 码升序排列；默认每页 10 条，支持 10/20/50 条切换。合计栏展示当前查询条件下的记录条数、车辆数、用量合计与费用合计，并展示当前已勾选条数。
#### 3.1.4 业务规则与状态变化

| 规则编号 | 触发条件 | 业务规则 | 数据/状态变化 |
| -------- | -------- | -------- | ------------- |
| R01 | 单车多卡 | 单车流量费用 = 该车当月各 SIM 卡费用之和；单卡费用 = 该卡当月实际用量 × 该卡所属流量池单位成本 | 列表按车辆汇总展示 |
| R02 | 一车多池 | 同一车辆的多张 SIM 卡分属不同流量池时，分别按各池单位成本计算单卡费用后求和 | 详情中按卡拆分展示各自单位成本 |
| R03 | 跨月与月中变更 | 费用按自然月归属；SIM 卡在月中变更绑定车辆或项目时，按绑定有效时间将用量与费用分段归集至对应车辆与项目 | 分段结果分别计入对应车辆月度记录 |
| R04 | 未归属处理 | 未绑定车辆的费用与未归属项目的费用不得丢失，分别以「未绑定车辆」「未归属」展示 | 归入对应标识的记录 |
| R05 | 数据只读 | 列表与详情数据由系统核算生成，页面不提供人工新增、编辑与删除 | — |

#### 3.1.5 交互流程

1. 用户进入页面，系统按默认月份范围（近 12 个月）加载全部车辆的月度流量费用。
2. 用户设置统计月份、车牌号、VIN 码或归属项目后点击「查询」。
3. 系统按条件过滤并刷新列表、合计与分页，同时清空原有勾选并回到第一页。
4. 处理结果：
   - 成功 → 展示符合条件的记录与合计（条数、车辆数、用量合计、费用合计）
   - 无结果 → 展示空状态提示，合计清零
   - 起始月份晚于结束月份 → 不执行查询，提示调整月份范围
5. 用户点击「重置」：清空全部查询条件，恢复默认月份范围与全部数据，并回到第一页。
6. 分页与勾选：全选仅对当前页生效；单条勾选在切换页码后保留；查询、重置后清空勾选。

#### 3.1.6 异常处理

| 异常场景 | 触发条件 | 系统处理 | 用户反馈 | 恢复方式 |
| -------- | -------- | -------- | -------- | -------- |
| 月份范围非法 | 起始月份晚于结束月份 | 不执行查询，保留原列表 | 提示开始月份不能晚于结束月份 | 调整月份后重新查询 |
| 查询无结果 | 无匹配数据 | 展示空状态 | 暂无符合条件的记录，请调整查询条件 | 调整查询条件 |
| 车辆无绑定卡 | 该车当月无归属 SIM 卡 | 关联卡数与用量按 0 展示，费用为 0.00 | 列表中如实展示 | 在 SIM 卡管理中维护绑定关系 |
| 单位成本无法核算 | 流量池当月实际使用总量为 0 | 不按 0 元/GB 计入，该池相关记录的单位成本与费用不计入合计 | 对应字段显示「—」 | 待充值费用与用量数据核准后重新核算 |
| 用量数据缺失 | 外部用量数据未同步 | 该车当月记录标记数据待补充 | 列表中如实展示 | 数据补齐后重新核算 |

## 4. 业务规则汇总

### 4.1 唯一性规则
同一车辆与同一统计月份在列表中唯一对应一条记录；跨项目的车辆按当月有效归属项目归集。
### 4.2 删除规则
本期不支持删除。费用数据由系统按月度核算生成，页面不提供删除入口。
### 4.5 计算规则
1. 单位成本 = 流量池当月充值费用总额 ÷ 流量池实际使用总量；分母一律为流量池当月实际已使用流量总量，不使用套餐额度或流量池总额度。
2. 单卡费用 = 该卡当月实际使用流量 × 该卡所属流量池单位成本。
3. 单车费用 = 该车当月全部 SIM 卡费用之和；多卡分属不同流量池时分别计算后求和。
4. 单车用量 = 该车当月全部 SIM 卡实际使用流量之和。
5. 单车加权平均单位成本 = 单车费用 ÷ 单车用量。
6. 流量使用率 = 单车用量 ÷ 该车关联 SIM 卡套餐额度合计。
7. 精度：用量与费用保留 2 位小数，单位成本保留 2 位小数，流量使用率保留 1 位小数。
8. 月度结束后生成当月正式核算结果；月中不生成实时预估费用。
### 4.6 校验规则

| 场景 | 校验内容 | 校验不通过处理 |
| ---- | -------- | -------------- |
| 查询 | 起始月份不得晚于结束月份 | 不执行查询并提示 |
| 核算 | 流量池当月实际使用总量大于 0 | 总量为 0 时标记无法核算，不按 0 元/GB 计入 |

### 4.7 审批权限规则

## 8. 已确认项与待确认项

**已确认项：**
1. 采用单口径核算：流量费用 = 当月实际用量 × 单位成本，本期不做月中实时预估费用。
2. 页面形态为月度汇总台账，每车每月一条记录，数据由系统核算生成且只读。
3. 统计范围仅车辆；页面不展示数据状态，不提供变更记录与人工新增、编辑、删除。
4. 充值费用不在本页面导入，后续由其他核算模块接入数据。
5. 查询条件为统计月份、车牌号、VIN 码与归属项目，其中车牌号与 VIN 码分开查询。

**待确认项：**
1. 充值费用与单位成本数据的接入模块、接入时间与数据粒度。
2. 车辆月中变更 SIM 卡绑定或项目归属时，用量与费用的分段归集是否按日粒度落地。
3. 其他网联资产（机器人、摄像头、对讲机）纳入本页面的时间与范围。
4. 各角色数据权限范围的最终落地方式。

## 9. 验收标准

1. 「费用管理 > 流量费用 > 流量费用明细」可从顶部模块与侧栏进入，导航高亮与当前页一致，页面无脚本错误。
2. 默认展示近 12 个月数据，按统计月份倒序排列；统计月份、车牌号、VIN 码、归属项目可组合查询，重置后恢复默认范围与全部数据。
3. 列表字段完整：统计月份、车牌号、VIN 码、归属项目、关联卡数、当月用量、流量使用率、单位成本与流量费用；合计栏展示条数、车辆数、用量合计、费用合计与已选条数。
4. 分页支持每页 10/20/50 条；当前页全选、单条勾选跨页保留；查询、重置后清空勾选并回到第一页。
5. 点击「详情」可查看单车单月汇总信息与按 SIM 卡拆分的用量、单位成本与费用；关闭详情后列表查询条件、勾选与页码保持不变。
6. 导出规则符合 3.3.5：已勾选导出选中，未勾选二次确认后导出全部，无数据不生成空文件。
7. 月份范围非法、查询无结果、车辆无绑定卡等场景按第 3 章异常处理规则给出反馈。
