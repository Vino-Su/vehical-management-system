## 1. 业务背景与使用角色

### 1.1 业务背景

车辆管理系统服务于多类使用方，不同使用方的业务场景差异较大（如环卫作业、运输配送、智能驾驶测试、租赁管理等），难以通过有限的强约束字段（如"归属项目"为单一值、"车辆状态"为固定枚举）统一表达所有业务分组诉求。

为弥补既有字段在"灵活分组、多维检索、自定义归类"上的不足，新增**标签管理**功能，作为车辆资产之上的**轻量、多对多、用户自定义的虚拟分组层**。标签不影响车辆的状态、归属项目等既有业务字段，仅作为检索与归类维度使用。

**标签与既有字段的关系定位：**

| 维度       | 既有字段（归属项目、车辆状态等）     | 标签                          |
| -------- | ---------------------- | --------------------------- |
| 产生方式     | 系统枚举/流程驱动，结构固定         | 用户自定义，灵活创建                  |
| 关联关系     | 车辆→单值（如一个归属项目）         | 车辆↔多对多（一辆车可有多个标签）           |
| 是否影响业务流程 | 影响（分配、调度、退出等）          | 不影响（纯附加维度，仅用于检索与归类）         |

### 1.2 使用角色

| 角色       | 标签管理模块中的职责                              | 客户端   |
| -------- | -------------------------------------- | ----- |
| 管理员      | 管理所有公有标签组/子标签（增删改）、管理所有项目私有标签、为所有车辆打标/移出、按标签筛选、导出 | PC+APP |
| 项目经理     | 管理本项目私有标签组/子标签、为本项目车辆打标/移出（含公有标签）、按标签筛选、导出 | PC+APP |
| 财务人员     | 查看所有标签、按标签筛选、导出                        | PC    |
| 管理层      | 查看所有标签、按标签筛选                           | PC    |
| 车队队长/司机  | 查看自身项目范围内的标签、按标签筛选                     | APP   |

### 1.3 核心目标与价值

| 目标维度   | 说明                                        |
| ------ | ----------------------------------------- |
| 灵活归类   | 提供两级（标签组→子标签）自定义结构，适配多元业务场景的分组诉求          |
| 多维检索   | 支持在车辆资产管理列表页按标签筛选，快速定位特定业务场景的车辆           |
| 公私分明   | 支持全局共享的公有标签与项目内部的私有标签，满足统一管理与项目自治双重诉求     |
| 统一管理   | 在标签管理页可按标签维度聚合查看车辆清单，并支持批量移出、导出           |
| 数据可溯源   | 标签的创建、修改、车辆打标/移出均纳入操作审计与变更日志               |

## 3. 功能详细设计

### 3.1 F01 标签管理列表页

#### 3.1.1 页面定位

车辆标签管理的核心入口页面，以两级树形结构展示标签组（一级）与子标签（二级），支持标签的维护与标签下车辆的统一查看。

#### 3.1.2 页面结构

页面自上而下分为三个区域：
1. **查询筛选区**：提供查询条件与操作按钮
2. **标签树区**：以可折叠展开的两级树形结构展示标签组与子标签
3. **分页区**：展示标签组分页控件与统计（标签组数据量较大时）

页面布局采用**左右分栏**：
- **左侧标签树区**：展示两级标签树，点击某个标签组或子标签后高亮选中
- **右侧车辆列表区**：展示当前选中标签（或标签组）下的车辆清单（详见 3.5）

#### 3.1.3 查询筛选区

查询条件与查询按钮放置在同一行显示。

| 元素     | 类型     | 配置说明                                       |
| ------ | ------ | ------------------------------------------ |
| 标签组名称  | 文本输入框  | 默认显示，支持对标签组名称与子标签名称模糊搜索                     |
| 标签类型   | 下拉单选   | 默认显示，枚举值：全部、公有、私有                          |
| 所属项目   | 下拉单选   | 默认显示，枚举值为项目列表；标签类型为"私有"时生效                 |
| 颜色     | 下拉单选   | 默认显示，枚举值：全部颜色 + 各预设颜色                       |
| 查询按钮   | 主按钮    | 点击执行查询，标签树刷新为查询结果                          |
| 重置按钮   | 次按钮    | 点击重置所有查询条件至默认状态（全部为空）                      |

**查询条件显示规则：**
- 共 4 个查询条件，全部默认平铺显示，无需展开/收起
- 查询条件与查询按钮、重置按钮在同一行排列

> 说明：「新建标签组」按钮位于左侧标签树面板头部（见 3.1.4）；「导出」按钮位于右侧车辆列表操作区（见 3.5.4），导出对象为当前选中标签下的车辆列表。

#### 3.1.4 标签树区

**面板头部：** 标签树面板头部左侧显示"标签结构"标题与标签组统计（共 N 组），右侧放置「+ 新建标签组」主按钮（点击打开"新建标签组"弹窗，仅管理员、项目经理可见）；头部下方显示一行说明文字（标签用于车辆自定义分组归类，不影响车辆状态与归属项目等业务字段）。

**树形结构（两级，固定两层）：**

```
📂 公有标签
  ├── 📁 运营场景（标签组）
  │     ├── 🟢 早班车（子标签）
  │     ├── 🔵 夜班车（子标签）
  │     └── 🟠 保障车（子标签）
  ├── 📁 重点保障（标签组）
  │     └── 🔴 VIP保障（子标签）
📂 私有标签
  ├── 📁 鸠江项目专属（私有，归属：鸠江项目）
  │     ├── 🟣 测试车组（子标签）
  │     └── 🟢 临时调度（子标签）
```

**节点展示信息：**

| 节点层级    | 展示信息                                                |
| ------- | --------------------------------------------------- |
| 标签组（一级） | 标签组名称 + 类型标识（公有/私有） + 车辆数（该组下所有子标签的车辆去重计数）+ 展开/收起箭头 |
| 子标签（二级） | 颜色圆点 + 子标签名称 + 车辆数（该子标签下车辆数）                        |

**节点交互：**

| 操作         | 行为                                                  |
| ---------- | --------------------------------------------------- |
| 点击标签组名称     | 展开/收起其子标签；同时右侧车辆列表展示该标签组下所有车辆（聚合）                   |
| 点击子标签名称     | 右侧车辆列表展示该子标签下车辆                                     |
| 标签组行"操作"按钮  | 下拉菜单：编辑、新建子标签、删除                                    |
| 子标签行"操作"按钮  | 下拉菜单：编辑、删除                                          |
| 双击子标签颜色圆点   | （只读展示）无编辑动作                                          |

**排序规则：**
- 标签组按"排序值"升序排列，相同排序值按创建时间升序
- 子标签按"排序值"升序排列，相同排序值按创建时间升序
- 公有标签组排列在私有标签组之前

#### 3.1.5 分页区

标签组数量较大时支持分页：

| 配置项     | 规则                                |
| ------- | --------------------------------- |
| 每页条数选项  | 10、20、50、100，默认20                |
| 显示信息    | 标签组总数、当前页码/总页数                    |
| 翻页控件    | 首页、上一页、页码、下一页、末页                 |
| 切换每页条数  | 下拉选择，切换后从第一页重新加载                 |

#### 3.2.1 触发方式

#### 3.2.4 交互流程

1. 用户点击"新建标签组"或标签组"编辑" → 打开弹窗

5. 点击"取消" → 关闭弹窗，不保存任何数据

| 公有标签组  | 仅管理员                             |
| 私有标签组  | 管理员（所有项目）、项目经理（仅本项目）             |

### 3.4 F04 删除标签组/子标签

#### 3.4.1 触发方式

用户在标签树中点击标签组或子标签行"操作"→"删除"。

#### 3.4.2 前置校验

| 校验条件                          | 提示信息                          |
| ----------------------------- | ----------------------------- |
| 待删除标签组下存在子标签                | "该标签组下存在子标签，请先删除子标签后再删除标签组"   |
| 待删除子标签下存在关联车辆               | "该标签下存在 {N} 辆关联车辆，是否确认删除？删除后该标签与车辆的关联将一并解除" |

#### 3.4.3 交互流程

1. 用户点击"删除" → 系统执行前置校验
2. 若存在阻断条件（标签组下有子标签） → 提示并终止
3. 若存在关联车辆（子标签有车辆） → 弹出二次确认弹窗，提示将解除关联
4. 点击"确定"：
   - 删除标签组：仅当无子标签时允许，逻辑删除标签组
   - 删除子标签：逻辑删除子标签，并解除该子标签与所有车辆的关联关系
   - 删除成功 → 显示"删除成功"Toast提示，标签树刷新
   - 系统自动记录：对每辆受影响车辆记录一条变更日志（修改字段：标签，修改前：标签名，修改后：空）
5. 点击"取消" → 关闭确认弹窗，不执行删除

#### 3.4.4 删除权限规则

## 4. 业务规则汇总

### 4.1 标签结构规则

1. 标签结构固定**两级**：标签组（一级）→ 子标签（二级），不支持更深层级
2. 车辆关联的对象为**子标签（二级）**，标签组（一级）为纯分组容器
3. 标签组与子标签均为用户自定义，可灵活创建

### 4.2 标签与车辆的关联规则

1. 标签与车辆为**多对多**关系：一辆车可关联多个子标签，一个子标签可关联多辆车
2. 同一车辆与同一子标签的关联**唯一**，不可重复建立
3. 打标签**不改变**车辆的状态、归属项目等既有业务字段
4. 已存在车辆标签的关联，重复打标时跳过，不报错

### 4.3 公有/私有规则

| 维度     | 公有标签                          | 私有标签                              |
| ------ | ----------------------------- | --------------------------------- |
| 可见范围   | 全局所有用户可见                      | 仅该标签所属项目范围内用户（及管理员）可见             |
| 管理权限   | 仅管理员可增删改                      | 管理员（所有项目）、项目经理（本项目）可增删改           |
| 使用范围   | 所有用户可用于打标、筛选                  | 仅所属项目范围内车辆可被打该私有标签                |
| 标识     | 标签组类型="公有"                    | 标签组类型="私有" + 所属项目                |
| 私有标签归属 | —                             | 归属到具体项目（标签组级别设定）                   |

**私有标签可见性补充：** 私有标签组的可见性以"所属项目"为准；项目经理仅能看到本项目私有标签组；财务人员、管理层、司机按其数据权限范围内的项目可见对应私有标签。

### 4.4 操作权限规则

| 操作         | 管理员              | 项目经理            | 其他角色     |
| ---------- | ---------------- | --------------- | -------- |
| 新建/编辑/删除公有标签 | ✅                | ❌               | ❌        |
| 新建/编辑/删除私有标签 | ✅（所有项目）          | ✅（仅本项目）         | ❌        |
| 批量/单车打标签   | ✅（所有车辆，公有+私有标签）  | ✅（本项目车辆，公有+本项目私有标签） | ❌        |
| 批量/单车移出标签   | ✅                | ✅（本项目车辆）        | ❌        |
| 按标签筛选、查看   | ✅                | ✅               | ✅（按数据权限） |
| 导出         | ✅                | ✅               | 财务人员✅    |

### 4.5 删除与关联处理规则

1. 删除子标签：逻辑删除子标签，并解除其与所有车辆的关联；对受影响车辆记录变更日志
2. 删除标签组：仅当其下无子标签时允许；逻辑删除标签组
3. 车辆被逻辑删除（建档/资产管理中的删除）或状态变为"已报废/已处置"后：
   - 车辆与标签的关联关系**保留**，不在标签下车辆列表中展示
   - 标签本身不受影响，标签下车辆计数相应减少
   - 关联关系不做物理删除，便于后续数据溯源

### 4.6 变更日志联动规则

标签的打标/移出属于车辆维度的修改行为，统一纳入车辆资产管理的**变更日志Tab**记录：

| 操作         | 操作类型 | 修改字段 | 修改前     | 修改后     |
| ---------- | ---- | ---- | ------- | ------- |
| 打标签        | 修改   | 标签   | 空       | 标签组名称/子标签名称 |
| 移出标签       | 修改   | 标签   | 标签组名称/子标签名称 | 空       |
| 删除子标签导致解除关联 | 修改   | 标签   | 标签组名称/子标签名称 | 空       |

- 修改前/后值格式："{标签组名称}/{子标签名称}"，如"运营场景/早班车"
- 操作来源：Web端 / APP端
- 批量操作按"每辆车 + 每个标签"逐条记录

### 4.7 颜色规则

1. 标签组与子标签均支持颜色（预设8色色板，见 3.2.3）
2. 子标签颜色默认继承所属标签组颜色，可单独修改
3. 列表页与详情页均以颜色标签展示，颜色仅用于视觉区分，不承载业务含义
4. 预设色板：蓝、绿、橙、红、黄、紫、青、灰

### 4.8 标签唯一性规则

| 对象   | 唯一性范围                           |
| ---- | ------------------------------- |
| 标签组  | 同一"标签类型 + 所属项目"范围内名称唯一          |
| 子标签  | 同一标签组范围内名称唯一                    |

## 7. 页面与交互流程图

### 7.1 标签管理列表页流程

```
用户进入车辆标签管理
  → 显示标签管理列表页（默认加载标签树 + 选中第一个标签/标签组展示车辆）
  → 可选操作：
    ├── 输入查询条件 → 点击查询 → 标签树刷新
    ├── 点击"新建标签组" → 打开新建标签组弹窗
    ├── 点击标签组"操作" → 编辑 / 新建子标签 / 删除
    ├── 点击子标签"操作" → 编辑 / 删除
    ├── 选中子标签/标签组 → 右侧展示车辆列表
    │     ├── 点击"移入车辆" → 打开移入车辆弹窗
    │     ├── 勾选车辆 → 点击"批量移出" → 确认 → 移出
    │     ├── 点击车辆"移出" → 二次确认 → 移出
    │     └── 点击车辆"详情" → 跳转车辆资产详情页
    └── 点击"导出" → 导出标签清单/车辆清单
```

### 7.2 资产管理列表页标签操作流程

```
用户进入车辆资产管理列表页
  → 可选操作：
    ├── 查询区选择"标签" → 点击查询 → 按标签筛选车辆
    ├── 列表"标签"列展示车辆标签
    ├── 勾选车辆 → 点击"批量打标签" → 校验 → 打开批量打标签弹窗 → 选择标签 → 确定
    ├── 勾选车辆 → 点击"批量移出标签" → 校验 → 打开批量移出标签弹窗 → 选择移出标签 → 确定
    └── 点击车辆"详情" → 资产详情页 → 基础信息Tab"车辆标签"分组查看/编辑
```
