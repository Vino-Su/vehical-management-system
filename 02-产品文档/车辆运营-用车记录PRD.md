## 1. 目标与范围

运营人员按司机、车辆和时间检索绑车至交车的用车记录，查看单条详情，并导出选中或当前查询结果。高保真阶段使用本地示例数据，不接入后端。

## 2. 列表与筛选

| 类别 | 要求 |
| --- | --- |
| 查询条件 | 司机名称、车牌号支持模糊匹配；绑车日期、交车日期各支持起止范围；状态支持全部、已交车、用车中。全部包含数据异常记录。 |
| 查询区展示 | 参照车辆资产列表，并使用公共渐进筛选组件；首行按可用宽度依次展示司机名称、车牌号、状态、绑车时间、交车时间，放不下的条件默认收起。点击“展开更多”显示剩余条件，全部条件可在首行容纳时隐藏展开入口。 |
| 表格样式 | 参照车辆资产列表：48px 行高、Ant Design 复选框、状态标签及操作链接；本页全部表头和数据字段统一居中对齐；横向滚动时固定司机名称和操作列。 |
| 列表字段 | 司机名称、关联车牌号、绑车时间、交车时间、用车时长（min）、轨迹里程（km）、状态、查看操作。 |
| 状态口径 | 已交车展示时长与里程；用车中无交车时间、时长显示“进行中”、里程显示“—”；数据异常显示异常状态，时长和里程显示“—”。 |
| 日期规则 | 起始日期不能晚于结束日期；指定交车日期时，未交车记录不匹配。查询、重置均回到第一页并清空已选记录。 |
| 分页 | 默认每页 10 条，支持 10、20、50、100 条；显示总条数和页码，无结果展示空状态。 |

## 3. 详情与导出

1. 点击“查看”打开详情弹窗，展示司机名称、脱敏电话、车牌、所属项目、绑车与交车时间、双方操作员、用车时长、轨迹里程、状态和备注；遮罩、关闭按钮及 Esc 可关闭。
2. 当前页全选仅选择本页记录；单条选择跨页保留，查询或重置时清空。显示已选数量并可清空选择。
3. 存在勾选时导出选中记录；未勾选时导出当前查询条件下全部记录。导出前弹窗展示条数与可编辑文件名；生成可由 Excel 打开的 UTF-8 CSV 文件，字段顺序与列表一致，不含选择和操作列。
4. 无查询结果时不生成空文件，并给出提示。

## 4. 页面与验收

页面文件：`03-高保真页面/vehicle-operation/vehicle-use-records.html`。从页面索引及公共导航均可进入，导航高亮正确。查询、重置、详情、选择、分页、导出、空状态均可交互；在 1366×768 和 1920×1080 下不重叠，表格窄屏时可横向滚动。视觉遵循平台 `UI_design_WEB` 规范。
