## 1. 业务背景与使用角色

### 1.1 业务背景

车型管理模块是车辆管理系统中系统管理的核心基础数据模块，负责对系统中涉及的所有车型进行统一管理。车型数据是车辆建档、车辆资产管理、车辆调拨等业务模块的数据来源基础，为各业务模块提供统一、规范的车型信息引用。

车型管理的核心特点：
- **一车型多版本**：同一车型可存在0至多个版本，各版本在底盘、动力、参数等方面存在差异；无版本车型允许先建立基础目录，补充版本后才可被车辆建档引用
- **全局共享**：车型数据为全系统共享的基础数据，无项目归属隔离
- **版本追溯**：支持对车型的修改操作进行变更日志记录，实现数据可溯源

本模块与关联模块的关系：
- 车辆建档模块：引用车型数据，选择车型名称+版本后自动填充关联字段
- 车辆资产管理模块：引用车型数据展示车辆所属车型信息

### 1.2 使用角色

| 角色       | 车型管理模块中的职责                     | 客户端   |
| -------- | ------------------------------- | ----- |
| 管理员      | 查看全部车型、新建/编辑/删除车型、新建版本 | PC    |
| 项目经理     | 查看全部车型、新建/编辑/删除车型、新建版本       | PC    |
| 财务人员     | 查看全部车型                          | PC    |
| 管理层      | 查看全部车型                          | PC    |
| 车队队长/司机  | 查看全部车型（如系统管理入口开放）              | APP   |

### 1.3 核心目标与价值

| 目标维度   | 说明                                |
| ------ | --------------------------------- |
| 数据标准化  | 统一管理车型数据，避免各业务模块车型信息不一致        |
| 版本管理   | 支持同一车型多版本管理，适应车辆迭代升级场景         |
| 数据溯源   | 变更日志记录所有修改行为，支持数据变更追溯           |
| 操作便捷   | 可折叠行展示车型与版本关系，一目了然              |
| 数据复用   | 为车辆建档、资产管理等模块提供统一车型数据来源        |

## 3. 功能详细设计

### 3.1 F01 车型列表页

#### 3.1.1 页面定位

车型管理的统一入口页面，以可折叠行的形式展示车型及版本层级关系，支持多维度查询。

#### 3.1.2 页面结构

页面自上而下分为三个区域：
1. **查询筛选区**：提供查询条件输入与操作按钮
2. **数据列表区**：以可折叠表格形式展示车型数据
3. **分页区**：展示分页控件与数据统计

#### 3.1.3 查询筛选区

查询条件与查询按钮放置在同一行显示。

| 元素     | 类型       | 配置说明                                                  |
| ------ | -------- | ----------------------------------------------------- |
| 车型名称（中）| 文本输入框    | 默认显示，支持模糊搜索                                           |
| 车型名称（英）| 文本输入框    | 默认显示，支持模糊搜索                                           |
| 车型版本   | 文本输入框    | 默认显示，支持模糊搜索                                           |
| 车型别名   | 下拉单选     | 默认显示，枚举值：扫路车、运输车、小型清洗机、小型扫路机、皮卡等                   |
| 车型编码   | 文本输入框    | 收起，展开后显示，支持模糊搜索                                       |
| 车型来源   | 下拉单选     | 收起，展开后显示，枚举值：自研、非自研                                 |
| 动力类别   | 下拉单选     | 收起，展开后显示，枚举值：纯电动、柴油、汽油、混动、天然气                        |
| 排放标准   | 下拉单选     | 收起，展开后显示，枚举值：国三、国四、国五、国六、纯电动、非道路移动机械                 |
| 整车厂商   | 文本输入框    | 收起，展开后显示，支持模糊搜索                                       |
| 创建人    | 文本输入框    | 收起，展开后显示，支持模糊搜索                                       |
| 创建时间   | 日期范围选择器  | 收起，展开后显示                                               |
| 查询按钮   | 主按钮      | 点击执行查询，列表刷新为查询结果                                      |
| 重置按钮   | 次按钮      | 点击重置所有查询条件至默认状态（所有条件为空）                              |
| 展开/收起  | 文字链接     | 默认仅显示前4个查询条件，点击展开显示所有查询条件，再次点击收起                     |
| 新建车型按钮 | 主按钮      | 点击打开新建车型信息页面；仅管理员、项目经理可见                            |

**查询条件显示规则：**
- 默认显示前4个查询条件：车型名称（中）、车型名称（英）、车型版本、车型别名
- 其余查询条件收起，点击"展开"后显示全部查询条件
- 查询条件与查询按钮、重置按钮在同一行排列

#### 3.1.4 数据列表区

列表采用**可折叠行**设计，外层行为车型维度信息，内层行为版本维度信息。

**外层行（车型行）显示字段：**

| 序号 | 字段名      | 字段标识           | 宽度建议   | 对齐方式 | 说明              |
| -- | -------- | -------------- | ------ | ---- | --------------- |
| 0  | 展开图标     | expand_icon    | 50px   | 居中   | 点击展开/收起该车型的版本行  |
| 1  | 车型名称（中）  | model_name     | 180px  | 左对齐  |                 |
| 2  | 车型名称（英）  | model_name_en  | 180px  | 左对齐  |                 |
| 3  | 车型别名     | model_alias    | 140px  | 左对齐  | 枚举值展示           |
| 4  | 车型编码     | model_code     | 140px  | 左对齐  |                 |
| 5  | 车型来源     | model_source   | 120px  | 左对齐  | 自研/非自研          |
| 6  | 创建人      | creator        | 120px  | 左对齐  |                 |
| 7  | 创建时间     | create_time    | 180px  | 左对齐  | 格式：YYYY-MM-DD HH:mm:ss |
| 8  | 操作       | actions        | 280px  | 居中   | 车型详情、编辑车型、新建版本、删除车型 |

**内层行（版本行，展开后显示）显示字段：**

| 序号 | 字段名 | 字段标识 | 说明 |
| -- | ---- | ---- | ---- |
| 0 | 车型版本 | model_version | 所属车型下的版本 |
| 1 | 车辆型号 | vehicle_model | 当前版本对应的车辆型号 |
| 2 | 整车厂商 | manufacturer | 当前版本对应的整车厂商 |
| 3 | 创建人 | creator | 当前版本的创建人 |
| 4 | 创建时间 | create_time | 当前版本的创建时间，格式：YYYY-MM-DD HH:mm:ss |
| 5 | 更新人 | updater | 当前版本的最近更新人 |
| 6 | 更新时间 | update_time | 当前版本的最近更新时间，格式：YYYY-MM-DD HH:mm:ss |
| 7 | 操作 | actions | 版本详情、编辑版本、新建版本、删除版本 |

**折叠行交互规则：**
1. 默认所有车型行处于**收起**状态
2. 点击外层行的展开图标（或行任意区域），展开该车型对应的所有版本行
3. 展开状态下，再次点击收起
4. 按照创建时间由近到远倒序排列（车型行级别排序）

**操作列按钮（版本行）：**

| 操作   | 触发行为                        | 可见角色      |
| ---- | --------------------------- | --------- |
| 版本详情 | 打开该车型版本的版本详情页面（查看态）         | 所有角色      |
| 编辑版本 | 打开该车型版本的版本详情页面（编辑态）         | 管理员、项目经理  |
| 新建版本 | 打开新建版本页面，以该版本为模板复制版本参数与其他信息 | 管理员、项目经理  |
| 删除版本 | 弹出二次确认弹窗后删除该版本              | 管理员、项目经理  |

**车型行操作：**车型行最右侧「操作」列支持查看车型详情、编辑车型、新建版本和删除车型（车型级操作，与版本行「操作」列的版本级操作相互独立）。车型详情展示车型公共信息及关联版本；关联版本区字段与列表页版本子表保持一致（车型版本、车辆型号、整车厂商、创建人、创建时间、更新人、更新时间、操作），操作栏文案同为版本详情、编辑版本、新建版本、删除版本；车型详情页同时承载车型级字段的编辑入口与车型级变更日志的查看入口（见 3.7）；无版本车型展示空状态和新建版本入口。车型存在版本时，删除车型操作被阻断（车型删除仅校验版本数量，不做车辆引用校验）。

**操作文案口径：**两级操作文案统一采用「带层级后缀」口径——车型行为车型详情、编辑车型、新建版本、删除车型；版本行为版本详情、编辑版本、新建版本、删除版本。车型行「新建版本」与版本行「新建版本」的填充语义不同，见 3.5.2。

**行交互：** 行hover高亮。

#### 3.1.5 分页区

| 配置项     | 规则                                |
| ------- | --------------------------------- |
| 每页条数选项  | 10、20、50、100，默认10                |
| 显示信息    | 总记录数、当前页码/总页数                    |
| 翻页控件    | 首页、上一页、页码、下一页、末页                 |
| 切换每页条数  | 下拉选择，切换后从第一页重新加载                 |

**说明：** 分页作用于外层车型行。每页显示N个车型（含其版本行）。

### 3.2 F02 车型信息详情页

#### 3.2.1 页面定位

展示某一车型版本的完整字段信息，支持查看态与编辑态切换，底部展示变更日志模块，实现数据溯源。

#### 3.2.2 页面结构

页面自上而下分为：
1. **顶部操作栏**：包含"关闭"、"编辑版本"按钮
2. **信息内容区**：按分组展示车型及版本字段信息
3. **变更日志区**：展示该车型版本的操作变更记录
4. **底部操作栏**（编辑态）：包含"确定"和"取消"按钮，固定在页面底部

#### 3.2.3 信息分组与字段展示

信息按以下4个分组展示，各分组使用折叠面板或分组标题分隔：

| 序号 | 分组名称   | 说明                       |
| -- | ------ | ------------------------ |
| 1  | 车型信息   | 车型来源、名称、别名、用途分类、编码、编码头等 |
| 2  | 版本信息   | 车型版本、车辆型号、动力类别、排放标准等     |
| 3  | 主要参数信息 | 底盘、整车、发动机、电机、清扫/冲洗宽度等    |
| 4  | 其他信息   | 备注、附件                    |

**查看态**：所有字段只读展示，附件类字段支持点击预览/下载。

**编辑态**：字段按"是否支持编辑"规则变为可输入状态，必填项标红色星号。

#### 3.2.4 顶部操作栏

| 按钮     | 类型   | 可见角色             | 行为                                    |
| ------ | ---- | ---------------- | ------------------------------------- |
| 关闭     | 次按钮  | 所有角色             | 关闭当前详情页面，返回列表页                        |
| 编辑版本   | 主按钮  | 管理员、项目经理         | 进入编辑态，底部显示固定操作栏（确定/取消）               |
| 新建版本   | 主按钮  | 管理员、项目经理         | 打开新建版本页面，自动填充该车型相关信息                 |

#### 3.2.5 变更日志模块

位于信息内容区下方，以列表形式展示**本版本版本级字段**的变更记录。

**作用域口径：**
1. 本页仅展示作用域为「版本级」的记录（车型版本、车辆型号、动力类别、排放标准、主要参数信息、其他信息等字段）
2. 车型级字段（车型来源、车型名称（中/英）、车型别名、用途分类、车型编码、编码头）不出现在本页；车型级变更统一记入车型详情页变更日志（见 3.7、4.6）
3. 版本详情页编辑态以只读方式展示车型级字段、**不采集**其值（见 3.3.2），从来源上杜绝车型级记录落入本页

**修改行为记录字段：**

| 记录字段   | 说明               |
| ------ | ---------------- |
| 操作对象   | 被修改的车型版本（车型名称+版本号） |
| 操作类型   | 修改               |
| 修改字段   | 被修改的字段名称         |
| 修改前    | 修改前的值            |
| 修改后    | 修改后的值            |
| 操作人    | 执行修改的用户          |
| 操作时间   | 修改操作的时间          |
| 操作来源   | 操作来源标识（Web端/APP端等） |

**记录粒度：** 一次保存产生多个字段变化时，按字段拆分为多条记录，同一批次的记录共享同一操作时间与批次标识。

**删除行为记录字段（本期不落地实现）：**

| 记录字段   | 说明               |
| ------ | ---------------- |
| 操作对象   | 被删除的车型版本        |
| 操作类型   | 删除               |
| 操作人    | 执行删除的用户          |
| 操作时间   | 删除操作的时间          |
| 操作来源   | 操作来源标识           |

**列表显示：**

| 序号 | 字段名   | 宽度建议   | 对齐方式 | 说明         |
| -- | ----- | ------ | ---- | ---------- |
| 0  | 操作对象  | 180px  | 左对齐  | 车型名称+版本号          |

### 3.6 F06 删除确认

#### 3.6.1 触发方式

用户在版本行点击"删除版本"，或在车型行点击"删除车型"。

#### 3.6.2 前置校验

删除校验按对象分层，**校验项各自唯一、互不交叉**：

| 对象  | 校验条件                     | 提示信息                                                                       | 阻断操作 |
| --- | ------------------------ | -------------------------------------------------------------------------- | ---- |
| 车型版本 | 该版本关联车辆数 ≥ 1（唯一校验项）      | "该车型版本已被 N 台车辆引用，不可删除。请先在车辆资产中解除相关车辆的车型引用后再删除。"                            | 是    |
| 车型  | 该车型仍存在版本（唯一校验项）          | "该车型仍有 N 个版本，请先删除所属版本后再删除车型。若版本已被车辆引用，请先在车辆资产中解除相关车辆的引用。"                   | 是    |

**口径说明：**

1. **车辆引用锚定在"车型版本"维度**：车辆建档时必选"车型名称 + 车型版本"，因此引用关系只会挂在版本上，车型本身不会被车辆直接引用。
2. **车型删除不做车辆引用校验**：车型删除的前置条件是"无版本"，而无版本即意味着不存在任何车辆引用（引用必挂在版本上），故车型删除无需、也不做车辆关联校验。
3. **引用为实时引用口径**：只要存在关联车辆，一律不可物理删除，不做连带删除、不做快照兜底。

#### 3.6.3 交互流程

1. 用户点击"删除版本" → 系统执行版本引用校验（查询该车型版本的关联车辆数）
2. 关联车辆数为 0 → 弹出二次确认弹窗，内容包含车型名称、版本号和不可恢复提示
3. 点击"确定" → 删除版本；若这是最后一个版本，保留车型并显示无版本状态
4. 关联车辆数 ≥ 1 → 弹出阻断弹窗，**仅展示关联车辆数量**（不展示车牌明细），并提供"查看车辆"入口，按钮组合为"我知道了"（主）+"查看车辆"（次）
5. 点击"查看车辆" → 跳转车辆资产列表，并自动带入"车型名称（中）"与"车型版本"查询条件并执行查询，筛出该车型版本关联的车辆
6. 用户点击"删除车型" → 系统仅校验该车型是否仍存在版本
7. 存在版本 → 弹出阻断弹窗，提示"该车型仍有 N 个版本，请先删除所属版本后再删除车型"，并指引版本被引用时的处理路径（去车辆资产解除引用），弹窗内不查询车辆、不展示引用车辆、不提供跳转
8. 无版本 → 弹出二次确认弹窗 → 点击"确定" → 删除车型，列表刷新
9. 本期删除操作不记录变更日志（见 4.6）

#### 3.6.5 跨模块联动：版本引用校验 → 车辆资产列表

| 环节 | 规则 |
| --- | --- |
| 触发 | 版本删除被阻断时，阻断弹窗内的"查看车辆" |
| 跳转 | 车辆资产列表页（`vehicle-asset/vehicle-asset-list.html`），URL 携带 `modelName`（车型名称）、`modelVersion`（车型版本）两个参数 |
| 落地 | 目标页加载后自动回填"车型名称（中）"与"车型版本"两个查询条件并执行查询，筛出该车型版本关联的车辆 |
| 一致性要求 | 阻断弹窗展示的引用车辆数量，必须与目标页筛选结果行数一致 |
| 前置依赖 | 目标页"车型版本"下拉选项按列表实际数据去重生成，保证任意版本号均可被选中并生效（不写死候选值） |

## 4. 业务规则汇总

### 4.1 车型唯一性规则

1. **车型名称（中）全局唯一**：系统中不可存在重复的中文车型名称
2. **车型名称（英）全局唯一**：如填写，系统中不可存在重复的英文车型名称
3. **车型编码全局唯一**：如填写，系统中不可存在重复的车型编码

### 4.2 版本唯一性规则

1. **同一车型下版本号不可重复**：同一车型名称（中）下，车型版本字段值不可重复
2. **已被车辆引用的版本不可删除**：删除前需校验该车型版本的关联车辆数（实时引用口径，引用锚定在"车型版本"维度）

### 4.3 删除规则

1. 仅支持删除未被车辆引用的车型版本；引用为**实时引用**口径，引用关系锚定在"车型版本"维度（车型本身不会被车辆直接引用）
2. 车型存在版本时不可删除；车型无版本时即可删除——车型删除不做车辆引用校验（车型可删即意味着版本数为 0，必然不存在车辆引用）
3. 删除前需二次确认，确认时展示具体对象
4. 删除最后一个版本只删除版本，车型保留为无版本车型
5. 本期删除操作不记录变更日志（后续版本补齐，见 4.6）

### 4.4 载重分类计算规则

| 最大重量范围            | 载重分类  |
| ------------------ | ----- |
| 最大重量 ≥ 8000 KG     | 重卡    |
| 最大重量 ≤ 3000 KG     | 微卡    |
| 3000 KG < 最大重量 < 8000 KG | 轻卡    |

**说明：** 最大重量为空时，载重分类显示为空。

| ------ | ---------- | --------------------------- |

### 4.6 变更日志记录规则

1. 系统需要对用户对车型及车型版本的**修改**操作进行记录，按**字段作用域**归属，与操作入口页面无关：
   - **车型级字段**（车型来源、车型名称（中/英）、车型别名、用途分类、车型编码、编码头）→ 记入**车型级**变更日志，在车型详情页查看
   - **版本级字段**（车型版本、车辆型号、动力类别、排放标准、主要参数信息、其他信息等）→ 记入**版本级**变更日志，在该版本详情页查看
2. 修改行为记录字段：操作对象、操作类型、修改字段、修改前、修改后、操作人、操作时间、操作来源
3. 记录粒度：一次保存按变更字段拆分为多条记录，同一批次记录共享操作时间与批次标识；字段值未发生变化时不记录
4. 比较口径：空值与未填写视为一致（显示为"—"）；载重分类等由其他字段联动自动计算的字段不单独记录
5. 变更日志按操作时间由近到远倒序排列
6. 变更日志为只读列表，不提供复选与导出；无记录时展示空状态「暂无变更记录」
7. 本期落地范围：仅修改行为；删除行为、新增（新建车型/新建版本）暂不记录
8. 车型级与版本级日志相互隔离：车型详情页不展示版本级记录，版本详情页不展示车型级记录

## 5. 页面交互流程图

### 5.1 车型列表页流程

```
用户进入车型管理
  → 显示车型列表页（默认加载第一页数据，所有车型行收起）
  → 可选操作：
    ├── 输入查询条件 → 点击查询 → 列表刷新
    ├── 点击重置 → 恢复默认查询条件（所有条件为空）
    ├── 点击展开图标 → 展开车型行，显示版本行
    ├── 点击车型详情 → 打开车型详情页（查看态）
    ├── 点击编辑车型 → 打开车型详情页（编辑态）
    ├── 点击版本详情 → 打开版本详情页（查看态）
    ├── 点击编辑版本 → 打开版本详情页（编辑态）
    ├── 点击新建版本 → 打开新建版本页面（车型行入口：仅继承车型信息）
    ├── 点击删除版本 → 前置校验 → 二次确认 → 删除版本
    ├── 点击删除车型 → 无版本且无引用时二次确认 → 删除车型
    └── 点击新建车型 → 打开新建车型页面
```

### 5.2 详情页流程

**5.2.1 车型详情页（车型级）**

```
用户进入车型详情页（查看态）
  → 可选操作：
    ├── 点击编辑车型 → 进入编辑态 → 修改车型级字段 → 确定（校验 + 写入车型级变更日志）/ 取消
    ├── 点击新建版本 → 打开新建版本页面（车型级入口：仅继承车型信息）
    ├── 关联版本区操作 → 版本详情 / 编辑版本 / 新建版本（版本级入口：复制该版本参数）/ 删除版本
    ├── 查看变更日志 → 车型级记录，按操作时间倒序只读查看
    └── 点击关闭 → 返回列表页
```

**5.2.2 版本详情页（版本级）**

```
用户进入版本详情页（查看态）
  → 可选操作：
    ├── 点击编辑版本 → 进入编辑态（不展示车型信息分组）→ 修改版本级字段 → 确定（校验 + 写入版本级变更日志）/ 取消
    ├── 点击新建版本 → 打开新建版本页面（版本级入口：复制该版本参数）
    ├── 查看变更日志 → 本版本版本级记录，按操作时间倒序只读查看
    └── 点击关闭 → 返回列表页
```

### 5.3 新建车型流程

```
用户点击新建车型
  → 打开新建车型页面
  → 填写车型必填信息
  → 可选添加首个版本并填写版本信息、主要参数、其他信息
  → 点击确定 → 校验 → 保存车型（及可选版本） → 关闭页面 → 列表刷新
  → 点击取消 → 关闭页面
```

### 5.4 新建版本流程

```
用户点击新建版本
  → 打开新建版本页面
  → 车型级入口（列表车型行 / 无版本空状态 / 车型详情页顶部操作栏）：仅继承车型信息，版本信息与参数留空
  → 版本级入口（列表版本行 / 版本详情页 / 车型详情页关联版本行）：以指定版本为模板复制版本参数与其他信息
  → 填写新版本号、车辆型号等
  → 可修改主要参数和其他信息
  → 点击确定 → 校验（版本号唯一性） → 保存 → 关闭页面 → 列表刷新
  → 点击取消 → 关闭页面
```
