## 1. 产品定位

单车费用管理是费用管理模块下的台账查询入口。统一读取费用管理中的费用明细，在查询期间内以车辆为行展示各项费用与合计，不提供独立费用录入。

## 2. 功能范围

### 2.1 单车费用台账

- 支持按车牌号、VIN码或归属项目查询；空条件查询全部有费用的车辆。
- 支持按费用发生日期区间查询；初始与重置后不限制日期，开始日期不得晚于结束日期。
- 每行对应一辆车，展示车牌号、VIN、所属项目、各项已接入费用及费用合计。
- 当前关联加油、加水、充电、流量费用明细；未开发费用来源不生成虚构记录。
- 各项金额与合计是台账字段，不另加统计卡片、占比图或趋势图。
- 点击某项费用可查看该车辆、该查询期间内的多条来源记录；点击单条记录的“查看详情”进入原费用页面并打开对应详情。
- “费用明细”操作查看该车辆所有费用类别的费用明细，详情中不展示来源记录字段。
- 支持勾选车辆后导出 CSV 数据；未勾选时不可导出。

### 2.2 与车辆详情费用信息的关系

车辆详情费用信息与台账的产品口径应一致，均以费用管理明细为来源。当前车辆详情“费用信息”尚未开放，此次接入范围为费用管理下的单车费用台账。

## 3. 数据关联

费用管理各明细模块通过统一字段关联单车台账：

| 字段 | 说明 |
| --- | --- |
| vehicle_id / VIN | 车辆唯一关联标识，不能仅以车牌号作为唯一键 |
| expense_type | 费用类别 |
| expense_date | 费用发生日期 |
| amount | 费用金额 |
| source_module | 来源费用模块 |
| source_bill_id | 来源单据编号 |
| status | 费用状态 |

单项费用等于查询范围内对应来源记录金额之和，费用合计等于各项费用之和。台账继承来源的费用口径，不新增审批或状态规则。能耗按发生日期过滤；流量费用按自然月归属，日期区间覆盖该月时计入完整月度费用，不进行按日摊分。来源记录的新增、修改、删除后重新查询时应反映在台账中。

## 4. 页面结构

`费用管理 / 单车费用管理 / 单车费用台账`

页面包含费用发生日期、车牌号、VIN码、归属项目查询、单车台账列表、费用明细查询与逐条详情追溯、分页和勾选导出。导出勾选的车辆台账，包含各项费用、费用合计与查询起止日期。未勾选时禁止导出并给出提示。

## 5. 验收标准

1. 页面从现有费用管理侧栏进入，沿用系统公共布局、筛选控件和分页组件。
2. 指定车辆和时间范围后，台账、来源记录与分页按同一查询结果更新；无结果显示空状态，非法时间范围保留原结果并提示。
3. 单车单项费用支持查看多条来源记录；每条记录的“查看详情”进入原费用页面并自动打开对应详情。
4. 勾选导出结果与当前筛选范围内选中车辆的台账明细一致；未勾选时不可导出。
5. 台账各项金额可由来源明细复核，费用合计等于各项费用之和，不展示独立统计卡片或图表。
