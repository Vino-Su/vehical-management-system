## 2. 目标与范围

为车辆运营人员提供统一的能耗费用记录台账。加油、加水、充电三个台账为独立页面，仅通过费用管理左侧导航进入对应台账；页面内容区不展示页面标题和费用类型切换。导航栏本身不属于本期改造范围。

## 3. 台账通用功能

1. 支持按发生时间、车牌号、上报人及适用业务字段进行组合查询，重置后恢复全部记录。
2. 表格支持当前页全选、单条选择、横向滚动、项目公共分页组件提供的 10/20/50 条分页，以及当前筛选数量、能耗数量和费用合计。加油台账固定复选框后的车牌号列与最右侧操作列；加水、充电台账不固定列。
3. 支持新增、编辑、详情、变更记录、删除、导入、导出和凭证预览。删除需二次确认；无选中数据时导出当前筛选结果。
4. 新增和编辑时校验必填项，凭证上传支持 JPG/PNG，每类凭证最多三张。

## 4. 加油费用明细台账

| 类别 | 内容 |
| --- | --- |
| 查询字段 | 加油时间、车牌号、关联油卡、上报人 |
| 表格字段 | 车牌号、加油时间、加油量、单价、金额、关联油卡、油卡余额、当前里程、交易凭证、上报人 |
| 编辑字段 | 车辆、项目、上报人、加油时间、单价、油量、金额、支付方式、油卡、油卡余额、里程、备注、里程照片、交易凭证 |
| 金额规则 | 默认按加油单价乘以加油量自动计算；允许手动调整，并可恢复自动联动。 |

## 5. 加水费用明细台账

| 类别 | 内容 |
| --- | --- |
| 查询字段 | 加水时间、车牌号、上报人 |
| 表格字段 | 车牌号、加水时间、加水量、支付方式、加水金额、当前里程、上报人 |
| 编辑字段 | 车辆、项目、上报人、加水时间、支付方式、加水量、金额、里程、备注、里程照片、支付照片 |
| 金额规则 | 月付可以不填写金额；现金和线上支付必须填写金额。 |

## 6. 充电费用明细台账

| 类别 | 内容 |
| --- | --- |
| 查询字段 | 充电开始时间、车牌号、上报人 |
| 表格字段 | 车牌号、充电开始时间、充电时长、支付方式、充电度数、充电金额、当前里程、充电明细、上报人 |
| 编辑字段 | 车辆、项目、上报人、充电开始/结束时间、度数、电费、服务费、金额、支付方式、里程、备注、里程照片、充电明细截图、支付照片 |
| 金额规则 | 默认按电费加服务费自动计算；允许手动调整，并可恢复自动联动。结束时间必须晚于开始时间。 |
