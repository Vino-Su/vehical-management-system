## 2. 固定列长表格

### 2.1 使用场景

字段较多且总宽度超过内容区的业务表格，需在横向浏览时持续保留首个业务标识列与末尾操作列。表头首列为复选框时，复选框不固定。

### 2.2 使用方式

表格外层沿用 `.table-wrapper`，并增加 `.fixed-table`。通过 `data-fixed-first` 和 `data-fixed-last` 声明需固定的首尾列数量；通过 `data-fixed-min-width` 设置开始横向滚动的表格最小宽度。组件默认跳过首个复选框列；特殊表格可用 `data-fixed-start` 显式指定从第几个单元格开始固定。

```html
<div class="table-wrapper fixed-table"
     data-fixed-first="1"
     data-fixed-last="1"
     data-fixed-min-width="1280px">
  <table>...</table>
</div>
```

页面需要同时引入 `components/fixed-table.css` 与 `components/fixed-table.js`。动态增删行、分页重绘与容器尺寸变化由组件自动重算；脚本加载后也可调用 `FixedTable.refresh(target)` 手动刷新。

### 2.3 交互与视觉规则

1. 内容宽度未超过容器时，不显示横向滚动条。
2. 内容宽度超过容器时，仅中间列横向滚动，配置的首尾列保持可见。
3. 左右仍有可滚动内容时，对应固定列边缘显示轻量投影，提示可继续浏览。
4. 单元格内容保持单行，列宽不足时通过横向滚动查看，不得以自动换行压缩表格信息。
5. 固定列在表头、悬停行和选中行中保持与所在行相同的背景色。
6. 表格结构应保持常规表头与数据行，避免在同一行内混用跨列单元格与固定列配置。

## 3. 主从列表

### 3.1 使用场景

页面采用「左侧分组列表 + 右侧明细」的主从工作台结构时，左栏列表统一使用本组件承载。适用于按多个维度（项目、车型、设备类型、运营商、套餐等）分组浏览、组内逐条切换对象、且分组本身也可作为筛选范围的场景。

左栏宽度受限（264px ~ 304px），列表项需在最小高度内保持固定的信息层级与点击热区。

### 3.2 使用方式

页面需同时引入 `components/master-list.css` 与 `components/master-list.js`，并按固定结构组织左栏 DOM：

```html
<aside class="master-panel">
  <div class="master-heading">
    <h2 class="panel-title">车辆列表</h2>
    <span class="panel-total" id="panelTotal">共 0 辆</span>
  </div>
  <div class="master-filter" id="masterFilter">
    <div class="compact-field"><label for="f-vin">VIN码</label><input id="f-vin"></div>
    <div class="master-filter-extra" id="masterFilterExtra"><!-- 展开后显示的次级条件 --></div>
    <div class="compact-actions">
      <button class="master-filter-toggle" id="masterFilterToggle" type="button" aria-expanded="false" aria-controls="masterFilterExtra">
        <span id="masterFilterToggleText">展开更多</span><span class="master-filter-chevron">⌄</span>
      </button>
      <div class="compact-action-buttons">
        <button class="btn" type="button">重置</button>
        <button class="btn btn-primary" type="button">查询</button>
      </div>
    </div>
  </div>
  <div class="group-toolbar">
    <div class="segmented" id="group-mode" role="group" aria-label="分组方式">
      <button class="segment-btn active" type="button" data-mode="project">项目</button>
      <button class="segment-btn" type="button" data-mode="model">车型</button>
    </div>
    <span class="list-result" id="groupCount">0 个分组</span>
  </div>
  <div class="group-list" id="group-list"></div>
</aside>
```

列表内容由脚本驱动，分组、折叠、组内分批加载、选中态与空态均由组件渲染：

```js
const list = MasterList.init({
  container: '#group-list',             // 分组列表容器（必填）
  totalEl: '#panelTotal',                // 标题栏总数节点（可选）
  countEl: '#groupCount',                // 分组数量节点（可选）
  totalText: n => `共 ${n} 辆`,           // 总数文案（可选）
  items: () => filteredVehicles,         // 数据源：数组或返回数组的函数
  getId: v => v.id,                      // 稳定标识，默认取 item.id
  groupModes: [                          // 分组维度，首个为默认维度
    { key: 'project', label: '项目', of: v => v.project }
  ],
  sortItems: (a, b) => a.vin.localeCompare(b.vin),
  sortGroups: (a, b) => 0,               // 可选，默认：命中分组置首 + 无分组置末 + 中文排序
  isActive: v => v.id === activeId,      // 卡片选中态
  isGroupActive: k => k === groupKey,    // 分组行选中态
  activeGroupKey: () => '鸠江项目',        // 当前对象所在分组，用于置首与默认展开
  groupSelectable: true,                 // true：折叠与选中分离（箭头折叠、分组行选中）
  scopeRow: { text: '全部设备', count: () => 12, isActive: () => true, onSelect: fn },
  renderCard: v => ({
    primary: v.plate,                    // 主标识（必填）
    primaryClass: 'num',                 // 主标识附加类，如等宽数字
    dot: 'is-success',                   // 状态圆点修饰类，不传则不渲染
    dotTitle: '终端在线',
    meta: `${v.vin} · ${v.model}`,        // 次要信息，可传数组渲染多行
    metaClass: 'num'
  }),
  batchSize: 4,                          // >0 时组内分批加载
  loadMoreText: n => `显示更多 ${n} 张`,
  empty: { title: '暂无匹配的车辆', desc: '请调整筛选条件后重试' },
  onSelect: v => select(v.id),
  onGroupSelect: k => selectGroup(k),
  onModeChange: k => {}
});

list.reset();          // 查询、重置、切换分组维度后调用：重置折叠状态并重渲染
list.render();         // 仅重渲染（保留折叠状态），用于选中对象变化
list.setMode('model'); // 切换分组维度
```

### 3.3 交互与视觉规则

1. 标题栏固定 54px，标题左、总数右；总数文案表达业务量词（如「共 12 辆」「共 16 张」「共 12 台」）。
2. 检索区条件超过一项时默认仅展示主条件，其余条件收入「展开更多」，展开状态由 `.master-filter.is-expanded` 控制；展开入口靠左、重置与查询按钮靠右。
3. 分组工具栏最小 50px，左侧为分组维度分段按钮，右侧为当前分组数量。
4. 分组列表默认仅展开排序最前的分组，其余分组收起；折叠状态在选中对象变化时保留，仅在查询、重置与切换分组维度后重置。
5. 分组行最小 36px，命中项以浅蓝底高亮；分组可作为筛选维度时，箭头仅负责折叠、分组行负责选中，两个点击热区互不干扰。
6. 分组计数以浅灰圆角标签展示在分组行内，不单独响应点击。
7. 「无分组」固定排在所有分组之后，当前选中对象所在分组置首。
8. 卡片最小高度 68px；选中态使用浅蓝底 + 浅蓝描边，左侧 3px 主色标识条仅在选中态出现；主标识 14px/600，次要信息 12px/18px 次要色，最多两行。
9. 状态圆点 7px，按成功、警告、错误、主色、禁用五档取语义色，并带同色系浅色光晕。
10. 组内数据超过分批条数时，在组内末尾展示「显示更多 N 项」，逐批追加，不改变分组与折叠状态。
11. 列表为空时展示空态（主文案 + 引导副文案），不保留旧列表内容。

## 4. 可搜索选择器

### 4.1 使用场景

绑定、维护类表单中，需要从台账候选集里选取单个业务对象（车辆、设备、SIM 卡等）的场景。候选集可能达到数十至数百条，原生下拉无法按业务字段检索，统一改用本组件。

### 4.2 使用方式

页面需同时引入 `components/search-select.css` 与 `components/search-select.js`，容器仅需一个空节点，控件与下拉面板由组件生成：

```html
<div id="bindingVehicle"></div>
```

```js
const select = SearchSelect.init({
  container: '#bindingVehicle',            // 容器（必填）
  placeholder: '输入车牌 / VIN / 项目搜索',
  allowClear: true,                        // 显示清空按钮（业务语义为解除绑定）
  items: () => vehicles,                   // 候选集：数组或返回数组的函数
  getValue: v => v.vin,                    // 值
  getLabel: v => `${v.plate} · ${v.vin}`,  // 选中后输入框显示文本
  matchText: v => [v.plate, v.vin, v.project], // 参与匹配的字段
  groupOf: v => v.project,                 // 候选分组维度（可选）
  sortItems: (a, b) => 0,                  // 组内排序（可选）
  renderOption: v => ({                    // 候选展示数据
    primary: v.plate,                      // 主标识（必填）
    primaryClass: 'num',
    meta: `${v.vin} · ${v.project}`,       // 次要信息
    disabled: false,                       // 禁用项不可选中
    disabledReason: '已被 460041234567890 占用'
  }),
  empty: { title: '无匹配对象', desc: '请调整关键字后重试' },
  onChange: (value, item) => {}            // 选中或清空后回调（item 为 null 即清空）
});

select.getValue();      // 当前值
select.getItem();       // 当前选中项
select.setValue(vin);   // 程序化赋值（不触发 onChange）
select.setItems(list);  // 候选集变化后刷新（不触发 onChange）
select.clear();         // 清空（触发 onChange）
```

### 4.3 交互与视觉规则

1. 控件高度 32px、圆角 6px，与输入框一致；聚焦或展开时边框主色并带 2px 主色浅色外发光。
2. 输入即搜：按 `matchText` 声明的字段做大小写不敏感模糊匹配，命中片段以主色加粗高亮；候选按 `groupOf` 分组展示。
3. 键盘操作：↑↓ 在可选候选间移动（自动跳过禁用项）、Enter 选中、Esc 关闭；关闭时输入框回填选中项文本，展开时清空以便直接输入。
4. 选中值后显示清空按钮，点击或输入框为空时按 Backspace 均触发清空。
5. 禁用候选（如已被其他设备占用的 SIM 卡）保持**可见但置灰、不可选中**，并在右侧展示 `disabledReason`；不得直接从候选中移除。
6. 无匹配结果时展示空态（主文案 + 引导副文案）。
7. 下拉面板挂载到 `body` 并以固定定位渲染，避免被弹窗等滚动容器裁切；容器滚动或窗口尺寸变化时跟随控件重新定位。

## 5. 表单弹窗样式

绑定、维护类弹窗共用 `components/modal-form.css`，统一字段栅格、只读回显、提示条、顶部对象预览条与弹窗宽度，避免各页面重复定义导致样式漂移。弹窗骨架（遮罩、头部、内容、底部）沿用 `common.css`。

- `.field-grid` + `.field` / `.field.full`：两列表单栅格，`.full` 占满整行；字段内控件样式仅作用于直接子元素，不影响字段内嵌组件（如可搜索选择器）。
- `.form-tip`：字段区提示条，整行占位。
- `.binding-preview`：弹窗顶部对象预览条（主标识 + 次要信息）。
- `.modal-box.device-modal`（720px）/ `.modal-box.binding-modal`（650px）：绑定维护类弹窗宽度。

- 车辆资产管理列表
- 可用车辆库
- 调度记录管理列表

### 6.2 主从列表

- SIM卡流量明细（左栏 SIM 卡列表）
- 车辆流量明细（左栏车辆列表）
- 设备管理（左栏设备列表）

### 6.3 可搜索选择器

- 设备台账、设备详情页的「维护绑定关系」弹窗（绑定车辆、绑定 SIM 卡）
- SIM 卡台账、SIM 卡详情页的「信息维护」弹窗（车辆、硬件识别码）

### 6.4 表单弹窗样式

- 设备台账、设备详情页的「新增/编辑设备」「维护绑定关系」弹窗
- SIM 卡台账、SIM 卡详情页的「信息维护」弹窗

### 6.5 公共顶部项目查看范围

复用 `common.js` 与 `common.css` 的公共导航，不增加独立页面或额外依赖。所有调用 `Common.initLayout()` 的业务页统一显示入口，旧页面的 `headerOptions.showProject:false` 不再隐藏入口。

- 入口采用标准 32px 控件，默认宽 184px，1440px 以下收敛为 168px；1120px 以下保留入口并收敛品牌区域，一级模块沿用横向滚动。
- 面板宽 296px，包含项目查看范围说明、项目数、名称搜索、全部授权项目与项目单选列表；选中项浅蓝底、主色文字和勾选标记。长项目名省略，入口可查看完整名称。
- `Common.projectOptions` 为现有项目演示列表；`Common.getSelectedProject()` 返回 `{id, name}`，`Common.selectProject(id)` 更新入口状态与预览记忆。选中状态按用户名称存储，读取不到或选择失效时返回全部授权项目。
- 搜索匹配项目名称，全部授权项目选项保留；无匹配项目显示空态。选中、外部点击、失焦和 Esc 收起，方向键可浏览选项，回车或空格选中；搜索唯一命中时回车选中。
- 项目面板和账号菜单互斥。刷新、侧栏跳转与顶部模块跳转后延续选择；本阶段不改变业务数据、统计、表单或权限。
